Cookie's Antispam

Overview

GitHub Repository | GitLab Mirror

LLM s did not just make spam easier to write; they made it cheap to write at scale. Antispam is my attempt to stop that wave at the mail server, before it reaches anyone's inbox. It is a classifier that reads incoming mail and decides whether it is spam, phishing, or legitimate - and a public blocklist of the hosts, spammers, and phishers that keep the networks under my protection busy every day.

The repository doubles as accountability: it names the providers that refuse to honor abuse@ reports because their paying customers happen to be the spammers. The lookup engine underneath is my GoLPM library, so classification stays fast even as the blocklist grows.

Features

  • Classifies incoming .eml files and stdin mail buffers as spam, phish, or ham.
  • Ships a curated blocklist of spammer hosts, ASN s, and phisher domains.
  • Flags hosts that cannot be blocked by other means (Google Forms, Azure, and friends).
  • Uses longest-prefix hashset maps for fast lookups, via the standalone GoLPM library.
  • Exports newly discovered spammers as a pull-request-ready JSON block.

Building

# install dependencies
sudo pacman -S go;

# build binary
cd /path/to/antispam/toolchain;
go run build.go;

# execute binary
cd /path/to/antispam/build;
./antispam-linux-amd64;

Usage

The tool is meant to be wired into a cronjob , or into an exec or filter event on the mail server. It can run on .eml files or directly on incoming mail buffers via stdin . 

# show help
antispam;

# view an email and check for spam indicators
antispam view path/to/mail.eml;

# if an email is spam, return exit code 1
antispam classify path/to/mail.eml;

# mark an email as spam, output new spammer ready for pull-request
antispam mark --json path/to/mail.eml;

Toolchain

The following tools help manage large folders of spam, malware, and phishing emails. Copy your email files to the /mails folder and run the scripts afterwards. 

# Cleanup spam
cd /path/to/antispam/toolchain;
go run cleanup.go --spam;

# Cleanup from allowlisted domains
go run cleanup.go --from="@example.com";

# Show whether E-Mails are classified as Spam or NotSpam
go run learn.go;

Cleanup Spam E-Mails

The cleanup script removes all files in the /mails folder that match its selection criteria, so trusted sources can be skipped no matter how they are classified. 

go run cleanup.go --from="johndoe@example.com";
go run cleanup.go --from="@example.com";
go run cleanup.go --domain="example.com";
go run cleanup.go --spam;

Discover Malicious ASNs

(Currently work-in-progress, so use with manual oversight.)

The discover script tries to combat the shell game that certain cyber terrorist nations play to avoid international sanctions. It discovers e.g. Russian, Iranian, or Chinese phishing and fraud companies that are part of international scam and malware campaigns. 

# discovers neighboring ASNs that are likely spam providers, too
go run discover.go --domain="example.com";

Learn Spam E-Mails

The learn script classifies all files in the /mails folder and shows the reasons. 

go run learn.go;
