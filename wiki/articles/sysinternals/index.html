System Internals

This learning path covers the internal architecture of modern operating systems from the perspective of a security researcher. The articles explain kernel design, privilege boundaries, memory management, scheduling, I/O, tracing, debugging, and exploitation primitives.

Every article includes practical commands you can run, kernel source references to read, and Docker containers with reproducible labs. The goal is not to read about kernels — it is to inspect, trace, and manipulate them.

It is required to complete the full Techniques learning path before beginning this section. The Red Team and Blue Team paths build on the material covered here.
