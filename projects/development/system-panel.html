System Panel

Overview

GitHub Repository | GitLab Mirror

System Panel is an adaptive GTK4 App for Linux which detects available system tools at runtime and presents only the views that can be used.

Behind the scenes it detects and uses common CLI tools and daemons that are integrated in Linux distributions coming with the systemd boot daemon and packages.

Features

The presented views depend on which packages have been installed:

View Requires Description
LAN nmcliand ethernet hardware Ethernet connect, profile editor
Wi-Fi nmcliand wireless hardware Wi-Fi Network scan, connect, profile editor
Bluetooth bluetoothctland bluetooth hardware Device scan, connect, disconnect, forget
Volume pactlandpulseaudio Input/output device sliders, mute toggles
Monitors xrandr Resolution selection, monitor arrangement
Wallpapers fehorhsetroot Browse and set wallpapers
Brightness brightnessctl Per-display backlight slider control
Services systemctland systemd Unit start/stop/edit, user/system mode
Autostart systemctland XDG autostart dir Desktop file enable/disable switches
Journal journalctl Color-coded journal log viewer
Battery upowerand battery Percentage, charge state, remaining time
Disks lsblkandudisksctl Partition and LUKS mount/unmount, health
Power Profile powerprofilesctl Power performance mode switcher
Time and Date timedatectl System time, date, timezone, NTP toggle
Themes /usr/share/themes/ GTK4/GTK3 theme browser with instant apply
Icons /usr/share/icons/ Icon theme browser with instant apply
Settings Always available View visibility toggles, dark mode, about

Usage

The GTK4 App is straightforward. Each View can Refresh and/or start the required Daemons with a button, and the App asks once for a session-stored sudo password if necessary.

Building

# Requirements: Go 1.26+, GTK 4.22+ development headers
make build;

Installation

sudo make install;
