Focus Mode

Silence Everyone Except the People Who Matter

Overview

GitHub Repository | GitLab Mirror

Focus Mode is an Android app for LineageOS and AOSP devices without Google Play services. It silences calls and notifications while letting a short allowlist of people through, and it can freeze every other app so nothing interrupts deep work.

Most focus apps ask you to block social media. This one takes the opposite route. It assumes the phone is the problem, not one app. When Focus Mode is on, the device drops into Do Not Disturb priority mode. Non-allowlisted calls are rejected, and all user-facing apps except the ones you keep alive are suspended. The launcher stays usable, the icons turn grey, and the phone finally behaves like a phone instead of a slot machine.

It is a personal tool for a LineageOS phone, built without Google Play services and without a network permission. Everything runs locally.

Features

  • Manage contacts for the allowlist through the system contact picker.
  • Enable Do Not Disturb priority mode for calls, messages, and conversations from starred contacts.
  • Suspends all other user-facing apps as device owner, including preinstalled apps.
  • Protects the launcher and system apps from suspension.
  • Keeps a configurable allowlist of apps running. NetGuard and Fennec are kept by default.
  • Keeps media playback and alarms audible while notifications and other apps are silenced.
  • Rejects incoming calls from anyone outside the allowlist.
  • Runs as a foreground service with a silent, ongoing status notification.
  • Restores the previous policy when Focus Mode is disabled.
  • Works without network permissions, Google services, or root.

Building

The app builds inside a Podman container, so no host Android SDK is required.

cd /path/to/focus-mode-app;
make;             # debug and release APKs
make debug;       # app/build/outputs/apk/debug/app-debug.apk
make release;     # app/build/outputs/apk/release/app-release.apk

The first run builds the Podman builder image automatically.

  • make rebuild-image forces a rebuild.
  • make distclean removes build output, caches, and the image.

Release builds use keystore.properties when present and fall back to the debug key otherwise.

Testing

Unit tests run on the JVM inside the same container.

cd /path/to/focus-mode-app;
make test;        # testDebugUnitTest
make lint;        # Android lint

The tests cover package filtering and phone-number matching, including the normalization rules used by the call screener. Instrumented tests are not part of the default build.

Usage: Setup

Install the APK and grant the in-app setup prompts. Contacts and notifications, Do Not Disturb access, and the Call Screening role.

cd /path/to/focus-mode-app;
make install;

Freezing other apps needs the Device Owner permission. This is a one-time, root-free step over ADB:

adb shell dpm set-device-owner engineer.cookie.focusmode/engineer.cookie.focusmode.admin.FocusDeviceAdminReceiver;

The device must have no accounts when this runs. No Google account, no DAVx5 account, no work profile, and no secondary users. Otherwise Android refuses the command. Reopen the app afterwards and the setup row turns green. Without device owner permission, Focus Mode still applies Do Not Disturb but won't be able to freeze other apps.

Usage: Allowlist

Open Allowed Contacts and pick a contact from the system picker. If a contact has several numbers, the app asks which one to allow. Allowlisted contacts are starred in the system Contacts app because the priority policy only lets starred callers and senders through. The app remembers which stars it added and removes them again when Focus Mode is disabled or a contact is removed.

Usage: Allowed Apps

Allowed Apps lists the apps that stay running while Focus Mode is active. This is the escape hatch for tools that need to keep working, such as a firewall or a web browser. The default list contains NetGuard and Fennec. The picker shows installed user-facing apps. Core system components are never selectable.

Usage: Deactivation

Disable Focus Mode from the main toggle or from the persistent notification.

If Focus Mode is the device owner, use the Deactivate button in the app before uninstalling. A plain uninstall is not enough while it owns the device. The app unsuspends every other app first.

For test builds with android:testOnly="true", the admin can also be removed over ADB:

adb shell dpm remove-active-admin engineer.cookie.focusmode/.admin.FocusDeviceAdminReceiver;
