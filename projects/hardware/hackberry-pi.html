Hackberry Pi CM5

Overview

The Hackberry Pi is a revolutionary device designed by ZitaoTech . It's a magnificent device that is essentially a smartphone based on Raspberry Pi hardware. Because it doesn't have any baseband modem, this is the definition of being the untrackable device.

There are multiple variants available as open-sourced designs. I give credit where credit is due, and ZitaoTech did an amazing job at designing them:

  • Hackberry Pi CM5 which I would recommend and uses a Raspberry Pi CM5 compute module as its SoC.
  • Hackberry Pi Zero that uses a Raspberry Pi Zero as its SoC and comes with two battery circuits.
  • Hackberry Pi 5 that uses a stock Raspberry Pi 5 as its SoC.

Teardown

The Hackberry Pi comes with an almost complete kit to build your own smartphone. In order to build it up, you need to get a fitting SSD for storage and a Raspberry Pi CM5 Lite compute module, as that one doesn't contain an onboard eMMC chip.

Flashing CM5 compute modules with an eMMC chip on them is a little quirky as it needs a flash board in order to be able to write on it. You can avoid that with the Lite variant, then the device will just boot from the SD card on its first boot and you can setup the SSD as the device's storage and install Linux on it.

As the hardware is based on Raspberry Pi hardware, pretty much any Linux distribution will run on it. Most distributions don't even really differ between generation 4/5 Raspberry Pis, as they use the same Broadcom 2711 or Broadcom 2712 CPU s which use the same firmware behind the scenes. So if the distribution images don't mention the generation 5 Raspberry Pi models specifically, it might be worth a shot to try out the generation 4 images.
