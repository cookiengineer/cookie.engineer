Cookie's Antispam

Overview

GitHub Repository | GitLab Mirror

The Antispam project is my attempt to fix the LLM spamming and phishing problem.

The repository reflects the spam that the networks under my protection receive on a daily basis. It also includes providers that refuse to abide with the abuse@ report policies because they have a conflict of interest towards their paying customers (obviously).

The dataset is maintained in the /source/insights folder and it differs between the following types of entries :

  • hosts which are specific domains that cannot be blocked by other means (yet).
  • spammers which are known to offer spam campaigns as a service (usually under the umbrella of AI targeted marketing campaigns).
  • spammers/unblockable which are known to send a lot of spam via e.g. Google Forms Scams or Microsoft Azure to bypass Microsoft Exchange Filters.
  • phishers which are known to send phishing and malware campaigns.

The abstractions behind the scenes use a form of longest-prefix hashset maps which allows this dataset to be computable in a faster manner than with LPM tries. The standalone library is available as the GoLPM project.

Usage

The usage of this tool is intended to be used via cronjob s or via an exec or filter event. It can be used manually on the .eml files or directly on incoming email buffers via stdin . 

# show help
antispam;

# view an email and check for spam indicators
antispam view path/to/mail.eml;

# if an email is spam, return exit code 1
antispam classify path/to/mail.eml;

# mark an email as spam, output new spammer ready for pull-request
antispam mark --json path/to/mail.eml;

Building

# install dependencies
sudo pacman -S go;

# buuild binary
cd /path/to/antispam/toolchain;
go run build.go;

# execute binary
cd /path/to/antispam/build;
./antispam-linux-amd64;

Toolchain

The following tools are available to manage large folders of spam/malware/phishing emails. In order to use them, copy your email files to the /mails folder and run the scripts afterwards. 

# Cleanup spam
cd /path/to/antispam/toolchain;
go run cleanup.go --spam;

# Cleanup from allowlisted domains
go run cleanup.go --from="@example.com";

# Show whether E-Mails are classified as Spam or NotSpam
go run learn.go;

Cleanup Spam E-Mails

The cleanup script removes all files in the /mails folder that match its selection criteria. This is intended to skip emails from trusted sources, no matter whether they are classified or spam or not. 

go run cleanup.go --from="johndoe@example.com";
go run cleanup.go --from="@example.com";
go run cleanup.go --domain="example.com";
go run cleanup.go --spam;

Discover Malicious ASNs

(Currently work-in-progress, so use with manual oversight)

The discover script tries to combat the shell game that certain cyber terrorist nations are playing to avoid international sanctions. This is intented to discover e.g. Russian, Iranian or Chinese phishing/fraud companies that are part of international scam and malware campaigns. 

# discovers neighboring ASNs that are likely spam providers, too
go run discover.go --domain="example.com";

Learn Spam E-Mails

The learn script classifies all files in the /mails folder and shows the reasons. 

go run learn.go;
