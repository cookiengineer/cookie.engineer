Privilege Escalation

This learning path covers Linux kernel privilege escalation exploits, each documented as professional writeups with reproducible exploits and hands-on CTF containers.

It is required to complete the full Fundamentals learning path before beginning this section. The Sysinternals path provides the kernel internals knowledge necessary to understand the exploitation techniques.
