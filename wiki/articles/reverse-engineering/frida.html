Frida Instrumentation

Dynamic instrumentation with Frida to hook functions, trace execution, bypass anti-analysis, and modify runtime behavior on Linux.

Overview

Frida is a dynamic instrumentation toolkit that injects a JavaScript engine into a running process to hook functions, trace execution, and rewrite behavior at runtime. It works on exported symbols, unexported internal functions, and arbitrary instruction addresses without recompilation. After reading, you can attach Frida to a Linux process, intercept libc calls, replace anti-debug checks, trace code with Stalker, and build analysis scripts.

Required Reading

  • /wiki/articles/reverse-engineering/ld-preload.html - the LD_PRELOAD approach to function hooking
  • /wiki/articles/reverse-engineering/gdb-malware.html - debugging malicious binaries

Architecture

Frida consists of three components:

  1. frida-core - the injection engine. Uses ptrace on Linux to attach, injects a shared library ( frida-agent.so ) into the target process, and establishes a communication channel (pipe or Unix socket).
  1. frida-gum - the instrumentation library inside the target. Provides Interceptor (function hooking), Stalker (code tracing), Memory (read/write/scan), Module (symbol resolution), and NativeFunction / NativeCallback (native <-> JavaScript bridging).
  1. frida-python / frida-tools - the CLI interface. frida-trace auto-generates hook stubs, frida provides a REPL, and the Python bindings allow fully scripted instrumentation workflows.

Installation on Linux

pacman -S python-pip
pip install frida-tools

# Verify:
frida --version
# 16.x.x

# Test that injection works:
frida-ps -U             # list processes on USB device (Android)
frida-ps                # list processes on local system

The Python package includes the native Frida server components. No separate server is needed for local Linux instrumentation - Frida injects directly via ptrace .

Function Tracing with frida-trace

frida-trace generates JavaScript handler stubs for any function matching a pattern: 

# Trace every function whose name starts with "open":
frida-trace -i "open*" ./test_binary

# Output: Frida starts the binary and prints each open() call:
#          139401980751744    open(path="/etc/passwd", ...)
#
# Handlers are saved in __handlers__/libc.so/open.js
# Edit these files to customize behavior, then re-run.

# Multiple patterns:
frida-trace -i "open*" -i "exec*" -i "system" ./test_binary

# Trace functions from a specific library:
frida-trace -I "libssl.so" -i "SSL_write" -i "SSL_read" ./test_binary

Generated handler stub ( __handlers__/libc.so/open.js ): 

{
  onEnter(log, args, state) {
    log('open() called');
  },
  onLeave(log, retval, state) {
    log('open() => ' + retval);
  }
}

Edit to log the path argument:

{
  onEnter(log, args, state) {
    log('open(' + Memory.readCString(args[0]) + ')');
  },
  onLeave(log, retval, state) {
    log('  => fd=' + retval.toInt32());
  }
}

Interceptor: Ad-Hoc Function Hooking

Write a Frida script for precise control:

// hook_connect.js - intercept connect() and log C2 destinations

const connectPtr = Module.getExportByName('libc.so.6', 'connect');

Interceptor.attach(connectPtr, {
    onEnter(args) {
        // args[0] = sockfd (int)
        // args[1] = struct sockaddr* (pointer)
        // args[2] = addrlen (int)

        const sockfd = args[0].toInt32();
        const sa_family = args[1].readU16();

        if (sa_family === 2) {  // AF_INET
            const port = args[1].add(2).readU16();
            const ip = args[1].add(4).readByteArray(4);
            const ipStr = [ip[0], ip[1], ip[2], ip[3]].join('.');

            console.log(`[CONNECT] fd=${sockfd} -> ${ipStr}:${port}`);
        } else if (sa_family === 10) {  // AF_INET6
            const port = args[1].add(2).readU16();
            const ip = args[1].add(8).readByteArray(16);
            const parts = [];
            for (let i = 0; i < 16; i += 2)
                parts.push(((ip[i] << 8) | ip[i+1]).toString(16));
            console.log(`[CONNECT] fd=${sockfd} -> [${parts.join(':')}]:${port}`);
        }
    },

    onLeave(retval) {
        console.log(`[CONNECT] => ${retval.toInt32()}`);
    }
});

Run it:

frida -l hook_connect.js ./test_binary
# Or attach to a running process:
frida -l hook_connect.js -p $(pgrep target_process)

Module and Memory APIs

Core Frida API s for introspection: 

// List all loaded modules (shared libraries)
Process.enumerateModules().forEach(m => {
    console.log(`${m.name} @ ${m.base} (${m.size} bytes)`);
});

// Find a function by name (requires exported symbol)
const openAddr = Module.getExportByName('libc.so.6', 'open');
console.log(`open @ ${openAddr}`);

// Find a module's base address
const libcBase = Module.findBaseAddress('libc.so.6');
console.log(`libc base: ${libcBase}`);

// Read null-terminated string from memory
const str = Memory.readCString(ptr('0x7ffd12340000'));
console.log(str);

// Read raw bytes
const bytes = Memory.readByteArray(ptr('0x555555401000'), 64);
console.log(hexdump(bytes));

// Scan memory for a pattern
const matches = Memory.scanSync(
    libcBase,
    0x200000,  // scan 2MB
    '55 48 89 e5'  // push rbp; mov rbp, rsp - function prologue
);
matches.forEach(m => console.log(`prologue @ ${m.address}`));

// Write memory
Memory.protect(ptr('0x555555401234'), 6, 'rwx');
ptr('0x555555401234').writeByteArray([0x90, 0x90, 0x90, 0x90, 0x90, 0xc3]);

Calling Native Code

NativeFunction lets you invoke any C function from JavaScript - useful for testing individual functions or calling undocumented internal API s: 

// Define open() signature: int open(const char *path, int flags, ...)
const openFunc = new NativeFunction(
    Module.getExportByName('libc.so.6', 'open'),
    'int', ['pointer', 'int']
);

// Call it:
const path = Memory.allocUtf8String('/tmp/frida_test');
const fd = openFunc(path, 0x241);  // O_WRONLY | O_CREAT | O_TRUNC
console.log(`opened fd: ${fd}`);

// Define system(): int system(const char *command);
const systemFunc = new NativeFunction(
    Module.getExportByName('libc.so.6', 'system'),
    'int', ['pointer']
);
systemFunc(Memory.allocUtf8String('id > /tmp/frida_out'));

// Call an internal (non-exported) function by address:
// Ghidra found a decryption function at 0x555555401800
const decryptFunc = new NativeFunction(
    ptr('0x555555401800'),
    'pointer', ['pointer', 'int']
);
// Call it with allocated buffer
const buf = Memory.alloc(256);
buf.writeByteArray([0x00, 0x01, 0x02, 0x03]);
const result = decryptFunc(buf, 4);
console.log(`decrypted at: ${result}`);

Complete Function Replacement

Replace an entire function body with custom JavaScript logic:

// Replace ptrace() - common anti-debug check - to always "succeed"
const ptraceAddr = Module.getExportByName('libc.so.6', 'ptrace');

Interceptor.replace(ptraceAddr, new NativeCallback(
    (request, pid, addr, data) => {
        console.log(`[BYPASS] ptrace(${request}, ${pid}) -> returning 0`);
        return 0;  // "Success" - no debugger detected
    },
    'long', ['int', 'pid_t', 'pointer', 'pointer']
));

// Now all ptrace() calls in the target binary return 0.
// The binary thinks PTRACE_TRACEME succeeded.

Anti-debug bypass patterns:

// ptrace(PTRACE_TRACEME, ...) - most common anti-debug
Interceptor.replace(Module.getExportByName('libc.so.6', 'ptrace'),
    new NativeCallback((..._) => 0, 'long', ['int', 'pid_t', 'pointer', 'pointer']));

// getppid() - malicious code checks if parent is strace
Interceptor.replace(Module.getExportByName('libc.so.6', 'getppid'),
    new NativeCallback(() => 1, 'pid_t', []));

// prctl(PR_SET_DUMPABLE, 0) - prevent core dumps during analysis
const prctlAddr = Module.getExportByName('libc.so.6', 'prctl');
Interceptor.replace(prctlAddr,
    new NativeCallback((opt, ...args) => {
        console.log(`[BYPASS] prctl(${opt}) -> 0`);
        return 0;
    }, 'int', ['int', '...']));

Modifying Arguments and Returns

Alter function arguments and return values without replacement:

// Hook read() - modify the buffer after the call, before returning
Interceptor.attach(Module.getExportByName('libc.so.6', 'read'), {
    onEnter(args) {
        this.buf = args[1];
        this.count = args[2].toInt32();
        this.fd = args[0].toInt32();
    },
    onLeave(retval) {
        const n = retval.toInt32();
        if (n > 0 && this.fd === 0) {  // stdin
            console.log(`[READ] fd=0 got ${n} bytes`);
            // Overwrite read data with our own
            const injection = Memory.allocUtf8String("hacked\n");
            this.buf.writeByteArray(injection.readByteArray(6));
        }
    }
});

// Hook write() - modify data before it reaches the kernel
Interceptor.attach(Module.getExportByName('libc.so.6', 'write'), {
    onEnter(args) {
        const fd = args[0].toInt32();
        const buf = args[1];
        const len = args[2].toInt32();

        if (fd === 1 || fd === 2) {  // stdout/stderr
            const original = buf.readCString(len);
            console.log(`[WRITE] fd=${fd}: "${original}"`);
            // Filter output - replace sensitive data
            if (original.includes('password')) {
                const sanitized = Memory.allocUtf8String('[REDACTED]\n');
                args[1] = sanitized;
                args[2] = ptr(sanitized.readCString().length);
            }
        }
    }
});

// Hook connect() to redirect connections
Interceptor.attach(Module.getExportByName('libc.so.6', 'connect'), {
    onEnter(args) {
        const addr = args[1];
        const family = addr.readU16();

        if (family === 2) {  // AF_INET
            const originalIP = [addr.add(4).readU8(), addr.add(5).readU8(),
                                addr.add(6).readU8(), addr.add(7).readU8()];
            const port = addr.add(2).readU16();
            console.log(`[CONNECT] original target: ${originalIP.join('.')}:${port}`);

            // Redirect to localhost:9999 (our analysis listener)
            addr.add(2).writeU16(0x0f27);  // port 9999 in network byte order
            addr.add(4).writeU32(0x0100007f);  // 127.0.0.1
        }
    }
});

Hooking Internal Functions by Address

Hooking unexported internal functions requires finding their address through static analysis:

# In Ghidra: find the function at 0x00101800 (decryption routine)
# Translate VA to runtime address (for PIE: base + offset)

# In Frida, resolve at runtime:
						
// Get the binary's base address (PIE binaries load at random base)
const base = Module.findBaseAddress('target_binary');
if (!base) {
    console.log('Module not loaded by name - enumerate:');
    Process.enumerateModules().forEach(m => console.log(m.name));
}

// Offset from Ghidra: 0x1800
const decryptAddr = base.add(0x1800);

Interceptor.attach(decryptAddr, {
    onEnter(args) {
        console.log(`[decrypt] called with: buf=${args[0]}, len=${args[1]}`);
        // Dump the pre-decryption buffer
        const buf = args[0];
        const len = args[1].toInt32();
        console.log(hexdump(buf.readByteArray(Math.min(len, 128)), { offset: 0 }));
        this.output = args[0];  // save for onLeave
    },
    onLeave(retval) {
        // Dump post-decryption buffer
        console.log('[decrypt] result:');
        console.log(hexdump(this.output.readByteArray(128), { offset: 0 }));
    }
});

Hooking Inside a Function

Hook at an instruction-level offset within a function (e.g., right after a loop):

const functionStart = base.add(0x1800);
// Hook at functionStart + 0x4a (after the XOR loop finishes)
const afterLoopAddr = functionStart.add(0x4a);

Interceptor.attach(afterLoopAddr, {
    onEnter(args) {
        // At this point, register RAX holds the decrypted value
        const decrypted = this.context.rax;
        console.log(`[decrypt] decrypted value: 0x${decrypted.toString(16)}`);
    }
});

this.context provides access to registers: 

Interceptor.attach(ptr, {
    onEnter(args) {
        // x86_64 registers
        console.log(`RAX=${this.context.rax}  RBX=${this.context.rbx}`);
        console.log(`RCX=${this.context.rcx}  RDX=${this.context.rdx}`);
        console.log(`RDI=${this.context.rdi}  RSI=${this.context.rsi}`);
        console.log(`RSP=${this.context.rsp}  RBP=${this.context.rbp}`);
        console.log(`R8=${this.context.r8}    R9=${this.context.r9}`);
        console.log(`RIP=${this.context.rip}`);
    }
});

Stalker: Code Tracing

Stalker follows every executed instruction, like Intel PIN but faster and integrated with Frida:

// Trace every instruction in a specific function
const targetFunc = base.add(0x1800);

// Find the function end (simplified - in practice, use symbol info or RET scanning)
const funcEnd = targetFunc.add(0x200);

Interceptor.attach(targetFunc, {
    onEnter(args) {
        this.threadId = Process.getCurrentThreadId();

        Stalker.follow(this.threadId, {
            transform(iterator) {
                let instruction;
                while ((instruction = iterator.next()) !== null) {
                    // Print each instruction as it executes
                    iterator.putCallout((context) => {
                        const rip = context.rip;
                        console.log(`0x${rip.toString(16)}: ${Instruction.parse(rip).toString()}`);
                    });
                    iterator.keep();
                }
            },
            events: {
                call: false
            }
        });
    },
    onLeave(retval) {
        Stalker.unfollow(this.threadId);
    }
});

// WARNING: Stalker generates enormous output - use with small code regions.
// For full-program tracing, prefer: Stalker.follow() with sampling or instruction counting.

Stalker sampling mode - count instructions per function without logging each one:

const counts = {};

Stalker.follow(Process.getCurrentThreadId(), {
    transform(iterator) {
        let instruction;
        while ((instruction = iterator.next()) !== null) {
            const blockAddr = iterator.blockAddress;
            iterator.putCallout((ctx) => {
                const key = blockAddr.toString();
                counts[key] = (counts[key] || 0) + 1;
            });
            iterator.keep();
        }
    }
});

// After execution stops, print the profile:
setInterval(() => {
    console.log(JSON.stringify(counts, null, 2));
}, 5000);

Crypto Tracing with Frida

Hook cryptographic libraries to capture plaintext and keys:

// Hook OpenSSL's EVP_EncryptInit_ex:
const sslBase = Module.findBaseAddress('libssl.so') ||
                Module.findBaseAddress('libssl.so.3');
if (sslBase) {
    const encInit = Module.getExportByName('libcrypto.so.3', 'EVP_EncryptInit_ex');
    if (encInit) {
        Interceptor.attach(encInit, {
            onEnter(args) {
                // args[0] = EVP_CIPHER_CTX*
                // args[1] = const EVP_CIPHER* (cipher type)
                // args[2] = ENGINE* (usually NULL)
                // args[3] = const unsigned char* key
                // args[4] = const unsigned char* iv

                const keyPtr = args[3];
                const ivPtr = args[4];

                if (!keyPtr.isNull()) {
                    console.log('[EVP_EncryptInit] key:');
                    console.log(hexdump(keyPtr.readByteArray(32)));  // assume AES-256
                }
                if (!ivPtr.isNull()) {
                    console.log('[EVP_EncryptInit] IV:');
                    console.log(hexdump(ivPtr.readByteArray(16)));
                }
            }
        });
    }
}

// Hook EVP_EncryptUpdate to capture plaintext:
const encUpdate = Module.getExportByName('libcrypto.so.3', 'EVP_EncryptUpdate');
Interceptor.attach(encUpdate, {
    onEnter(args) {
        const inBuf = args[1];
        const inLen = args[2].toInt32();
        if (inLen > 0 && inLen < 4096) {
            console.log(`[EVP_EncryptUpdate] plaintext (${inLen} bytes):`);
            console.log(hexdump(inBuf.readByteArray(inLen)));
        }
    }
});

// Hook EVP_DecryptUpdate for decrypted plaintext capture
const decUpdate = Module.getExportByName('libcrypto.so.3', 'EVP_DecryptUpdate');
Interceptor.attach(decUpdate, {
    onEnter(args) {
        this.outBuf = args[0];  // output buffer
        this.outLen = args[3];  // pointer to output length
    },
    onLeave(retval) {
        if (retval.toInt32() === 1) {
            const len = this.outLen.readInt();
            if (len > 0) {
                console.log(`[EVP_DecryptUpdate] decrypted (${len} bytes):`);
                console.log(hexdump(this.outBuf.readByteArray(len)));
            }
        }
    }
});

Frida with Podman Containers

Run Frida inside a podman container for malware analysis:

# Create analysis container with Frida pre-installed
podman run --rm -it --name frida-box \
  --cap-add=SYS_PTRACE \
  --security-opt seccomp=unconfined \
  archlinux:latest /bin/bash

# Inside container:
pacman -Syu python-pip --noconfirm
pip install frida-tools

# Copy the malware sample in, run:
frida -l hook_spy.js ./malware_sample
podman cp frida-box:/tmp/trace.log ./

The --cap-add=SYS_PTRACE flag is essential - Frida uses ptrace for injection and without it, attachment fails silently.

Hooking Static Binaries with Frida

Unlike LD_PRELOAD which cannot touch statically-linked binaries, Frida can hook them because it operates at the instruction level: 

# The binary is statically linked with musl libc:
file ./sample
# sample: ELF 64-bit LSB executable, x86-64, statically linked

# Frida handles this naturally - hook by address or exported symbol:
frida -l hook.js ./sample

When symbols are stripped, use Module.findExportByName() with null for the main executable: 

// Find a function by name in the main binary (stripped or not):
const funcPtr = Module.findExportByName(null, 'main');
if (!funcPtr) {
    // If stripped, find by scanning or use known offset from Ghidra:
    const base = Process.enumerateModules()[0].base;
    const funcPtr = base.add(0x1a50);  // offset from Ghidra
}

Complete Analysis Script

A general-purpose spy script for unknown Linux binaries:

/*
 * spy.js - Universal Frida hook script for Linux binary analysis
 *
 * Usage: frida -l spy.js ./target_binary
 *
 * Hooks: open/connect/execve/system/socket/bind/listen/write
 * Logs to stderr in JSON format for machine parsing
 */

const LIBC = 'libc.so.6';

function jsonLog(event, data) {
    const record = {
        timestamp: Date.now(),
        pid: Process.id,
        tid: Process.getCurrentThreadId(),
        event: event,
        ...data
    };
    console.error(JSON.stringify(record));
}

function hook(name, onEnterFn) {
    const addr = Module.findExportByName(LIBC, name);
    if (!addr) {
        console.error(`[-] Cannot find ${name} in ${LIBC}`);
        return;
    }
    Interceptor.attach(addr, {
        onEnter(args) {
            try { onEnterFn(args); } catch (e) {
                console.error(`[!] Error in ${name} hook: ${e}`);
            }
        }
    });
    console.error(`[+] Hooked ${name} @ ${addr}`);
}

// Filesystem
hook('open', function(args) {
    jsonLog('open', {
        path: Memory.readCString(args[0]),
        flags: args[1].toInt32()
    });
});

// Network
hook('connect', function(args) {
    const family = args[1].readU16();
    let addr = '(unknown)';
    if (family === 2) {  // AF_INET
        const ip = [args[1].add(4).readU8(), args[1].add(5).readU8(),
                    args[1].add(6).readU8(), args[1].add(7).readU8()].join('.');
        const port = args[1].add(2).readU16();
        addr = `${ip}:${port}`;
    }
    jsonLog('connect', { sockfd: args[0].toInt32(), target: addr });
});

hook('bind', function(args) {
    let port = '(unknown)';
    if (args[1].readU16() === 2)
        port = args[1].add(2).readU16();
    jsonLog('bind', { sockfd: args[0].toInt32(), port: port });
});

// Exec
hook('execve', function(args) {
    const path = Memory.readCString(args[0]);
    const argv = [];
    let i = 0;
    while (true) {
        const p = args[1].add(i * Process.pointerSize).readPointer();
        if (p.isNull()) break;
        argv.push(Memory.readCString(p));
        i++;
    }
    jsonLog('execve', { path: path, argv: argv });
});

hook('system', function(args) {
    jsonLog('system', { command: Memory.readCString(args[0]) });
});

// Backdoor detection
hook('socket', function(args) {
    jsonLog('socket', {
        domain: args[0].toInt32(),
        type: args[1].toInt32(),
        protocol: args[2].toInt32()
    });
});

// Runtime library loading (suspicious)
const dlopen = Module.findExportByName(null, 'dlopen');
if (dlopen) {
    Interceptor.attach(dlopen, {
        onEnter(args) {
            jsonLog('dlopen', { filename: Memory.readCString(args[0]) });
        }
    });
}

Read string Memory.readCString(ptr)
Read bytes Memory.readByteArray(ptr, len)

Frida vs Other Tools

Tool Hooks libc Hooks raw syscalls Hooks arbitrary addr Modify args/ret Runtime injection Static binary
LD_PRELOAD yes no no limited no no
strace (ptrace) n/a yes no no yes yes
GDB yes with catch syscall yes (breakpoints) yes yes yes
Frida yes via syscall hook yes yes yes yes
eBPF no yes (tracepoints) yes (uprobes) no yes yes

Frida combines the flexibility of GDB-level control with the programmability of LD_PRELOAD, while adding runtime injection that neither of the others provides.

Common Frida Errors

Failed to attach: unable to access process with pid 1234
    -> Kernel YAMA ptrace_scope is 1 or higher.
    -> Fix: echo 0 | sudo tee /proc/sys/kernel/yama/ptrace_scope
    -> Or set: kernel.yama.ptrace_scope = 0 in /etc/sysctl.d/10-ptrace.conf

Failed to attach: process not found
    -> The target binary or process does not exist.
    -> Check ps aux | grep <name>

Module 'libc.so.6' not found
    -> The binary uses a different libc (musl, uclibc) or is statically linked.
    -> Use Process.enumerateModules() to find the correct library name.
    -> On Alpine: use 'libc.musl-x86_64.so.1'

"TypeError: cannot read property 'readCString' of undefined"
    -> The function argument is NULL.
    -> Guard: if (!args[0].isNull()) ...

Challenge

Write a Go program that attaches to a target with ptrace , reads the first eight bytes of a function from /proc/<pid>/mem , and prints them as a Frida scan pattern. Feed the pattern to Memory.scanSync in a Frida script and confirm it matches the same address in the target process. 

package main

import (
	"fmt"
	"os"
	"strconv"
	"syscall"
)

func main() {
	if len(os.Args) != 3 {
		fmt.Fprintf(os.Stderr, "usage: %s <pid> <address>\n", os.Args[0])
		os.Exit(1)
	}
	pid, err := strconv.Atoi(os.Args[1])
	if err != nil {
		fmt.Fprintln(os.Stderr, "invalid pid")
		os.Exit(1)
	}
	addr, err := strconv.ParseUint(os.Args[2], 0, 64)
	if err != nil {
		fmt.Fprintln(os.Stderr, "invalid address")
		os.Exit(1)
	}
	if err := syscall.PtraceAttach(pid); err != nil {
		fmt.Fprintln(os.Stderr, "attach:", err)
		os.Exit(1)
	}
	defer syscall.PtraceDetach(pid)
	var ws syscall.WaitStatus
	if _, err := syscall.Wait4(pid, &ws, 0, nil); err != nil {
		fmt.Fprintln(os.Stderr, "wait4:", err)
		os.Exit(1)
	}
	mem, err := os.Open(fmt.Sprintf("/proc/%d/mem", pid))
	if err != nil {
		fmt.Fprintln(os.Stderr, "open mem:", err)
		os.Exit(1)
	}
	defer mem.Close()
	buf := make([]byte, 8)
	if _, err := mem.ReadAt(buf, int64(addr)); err != nil {
		fmt.Fprintln(os.Stderr, "read mem:", err)
		os.Exit(1)
	}
	fmt.Printf("address 0x%x first 8 bytes: %02x %02x %02x %02x %02x %02x %02x %02x\n",
		addr, buf[0], buf[1], buf[2], buf[3], buf[4], buf[5], buf[6], buf[7])
	fmt.Printf("frida pattern: '%02x %02x %02x %02x %02x %02x'\n",
		buf[0], buf[1], buf[2], buf[3], buf[4], buf[5])
}

Run it against a process you own (set kernel.yama.ptrace_scope=0 if attach fails), then paste the printed pattern into a Frida script that hooks the address and logs every call.
