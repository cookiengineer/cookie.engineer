jQuery Desktop

Overview

Download

The jQuery Desktop is an experiment that tried to implement a Web Browser based Desktop Environment which included common application functions.

It was used by some friends and me at the time during highschool. As you might have guessed, this project was written when I was a teenager, when Web Browsers were very slow and limited in what they can render. But it ran totally fine on Opera Turbo and IE5.5+ on Windows CE platforms.

Its backend was written in PHP version 4 and its frontend was written with the jQuery library. Most of the CSS was done with absolute positioning, as there were no draggable and neither droppable element features in the XHTML 1.1 Strict specification yet.

Over the years some random projects reused the code of this experiment and made fun and interactive user interfaces with it. Code-wise this was a prototype written by a teenager, and should be treated as such.

For the nostalgia effect and to be able to make some screenshots for this article, I migrated some of the codebase to PHP 5.6 so that it can run inside a container.

If you want to reuse the codebase, please rewrite the backend.

Usage

The zip file contains a Dockerfile that you can build with podman or any other docker compatible container daemon. 

cd /path/to/jquery-desktop;
podman build --name jquery-desktop .;
podman -p 8080:80 --name jquery-desktop jquery-desktop;

# Now visit http://localhost:8080 to feel some of the jQuery nostalgia
