Cookie's Forensics Tools

Overview

GitHub Repository | GitLab Mirror

The Forensics Tools mono repository contains my personal forensics tools that I need when I'm investigating an incident. They are something like a better bashrc , implemented in Go, without any kind of warranty to work at all.

Over the years some tools have been quite useful, and they're somewhat also expanded when I'm doing more CTF events and there's a use case for another tool.

The tools folder is separated by use-case. Each of the tools' root folder contains a README.md explaining the purpose of the forensics tools inside them. Make sure to read them carefully.

Building

The build process is fully integrated with the Go build toolchain. All of the software's dependencies are automatically downloaded and compiled if necessary.

The toolchain/build.go build script will build a separate install-forensics-tools program that can be deployed to another machine and executed there to install all the contained tool binaries. 

# build the installer
cd /path/to/forensics-tools/toolchain;
go run build.go;

Installation

After the installer has been built, it can be executed to install the binaries in the given ${PREFIX}/bin folder. 

# install the forensics tools
cd /path/to/forensics-tools;
chmod +x ./build/install-forensics-tools;
export PREFIX="/usr/local"; sudo ./build/install-forensics-tools;

Implemented Tools Features

  • archive-pack packs any known archive files
  • archive-unpack unpacks any known archive files
  • crx-dl downloads Chromium extension files
  • crx-extract extracts Chromium extension files
  • dns-iscensored checks whether a domain is censored
  • ffmpeg-to720p converts videos to x264 720p videos
  • ffmpeg-to1080p converts videos to x264 1080p videos
  • ffmpeg-tomp3 converts videos to mp3 files
  • git-serve serves a local git server
  • dyndns-goip updates goip.de DynDNS domains
  • gs-totiff converts documents to tiff images
  • http-serve serves a folder via HTTP
  • memdump-keepass finds a KeePass(XC) password in memory dump files
  • npm-dl downloads and extracts specific packages from the NPM registry
  • reddit-archive downloads subreddits and threads
  • sql-extract extracts a specific table from large SQL dump files
  • sql-tables lists a table index of large SQL dump files
  • torrent-magnetify adds default trackers to torrent magnet links
  • totp-extract extracts OTP password seeds from screenshots or camera photos of QR codes
  • yt-mp3 downloads streams as MP3 files
  • yt-mp4 downloads streams as MP4 files
  • yt-opus downloads streams as OPUS files
  • zip-bruteforce bruteforces the password of a ZIP file
  • zip-unmask unmasks ZIP files that have been XOR obfuscated
