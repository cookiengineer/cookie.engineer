Polyfillr Framework

Overview

Download

The Polyfillr Framework is a modern ES2016+ based framework for web development in the modern age. It aims to be completely transpiler-free and bundler-free whilst offering modern APIs and polyfills from ES6 Harmony and later.

It is split up between a Console Polyfill , an ECMAScript Polyfill and a Web Components Polyfill that allows to implement Web Components based on HTML Imports and Custom Elements .

Its design goals are to be as small in size as possible, and as standard compliant as possible, whilst embracing simplicity in its usage.

It can be used in Electron, NW.js , Desktop Browsers, WebKit Mobile, Safari Mobile, Chrome, Chromium, Firefox, Edge and outdated Internet Explorer variants in a reliable way.

All of its APIs require only ES3 as a baseline, as they're incrementally polyfilled. As its architecture avoids the use of ES6 generators and the yield keyword, no code is transpiled and parser differences in syntax cannot be supported, only more modern methods and data types.
