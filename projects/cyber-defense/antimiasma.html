Antimiasma

Overview

GitHub Repository | GitLab Mirror | Whitepaper

The Antimiasma project is a mitigation tool against the Miasma malware that was created by TeamPCP and was implemented using LLM s to generate its package ecosystem adapters for the implant spreading mechanisms.

Blogpost and Whitepaper

The detailed Blogpost about it is Malware Insights - Miasma Campaign and covers reverse engineering insights and technical details.

The detailed Whitepaper is published as Ephemeral Malware and is available freely for download. The Whitepaper covers technical details and insights to the malware and reactive strategies that TeamPCP were applying while observing maintainers trying to contain the damage.

Features

The mitigation tool supports detection and removal of all known spread vectors that have appeared during the (ongoing) campaigns. Most of the infected files and their structures have changed a bit over a series of malware implant changes during the campaign, which is why the mitigation tool will look for suspicious processes being executed.

The Antimiasma tool is able to mitigate all 17 of 17 unique malware samples. The only exception being here that pacman hooks that have been installed on the system need to be mitigated manually, due to pacman itself otherwise executing the malware payload when it has nested itself into the cleanup or uninstall hooks in /var/lib/pacman/local/* .

Name Type Infected File Discover Mitigate
Claude Code IDE .claude/settings.json yes yes
Cursor IDE .cursor/rules/setup.mdc yes yes
Gemini IDE .gemini/settings.json yes yes
VSCode IDE .vscode/tasks.json yes yes
AUR AUR Packages PKGBUILDand*.install yes #2
Composer PHP Packages composer.json yes yes
Go Go Packages go.mod yes yes
NPM NPM Packages package.json yes yes
Pacman Pacman Packages install yes #2
PIP PyPI Packages *-setup.pth yes #1
Miasma Blight Bun Implant .github/setup.js yes yes
Miasma Hades Bun Implant _index.js yes yes
Miasma Atomic eBPF Implant src/hook/deps yes yes

[1]: The pip install commands use compressed whl files for distribution. The *-setup.pth cannot be detected. Only after an infected package already ran the malware payload, the Miasma implant can be removed.

[2]: The implant requires manual removal of already installed packages that were discovered in /var/lib/pacman/local/* .

Usage

The Antimiasma tool automatically discovers all malware implants in a selected folder. After the discover run, you can remove the malware implants with a mitigate run. 

cd /path/to/antimiasma;

sudo go run cmds/antimiasma/main.go discover /;
sudo go run cmds/antimiasma/main.go mitigate /;
