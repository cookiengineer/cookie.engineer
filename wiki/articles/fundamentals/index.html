Fundamentals

This learning path teaches the fundamental basic knowledge for all other cyber security learning paths.

Learning Path

The articles in this section explain how the underlying technology works. These are not offensive or defensive guides. Instead, they explain operating systems, networking, protocols, memory, and security mechanisms that every security engineer should understand. It is recommended to complete these articles before diving into the Red Team or Blue Team learning paths.
