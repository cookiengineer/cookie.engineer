Ghidra Scripting

Automating reverse engineering with Ghidra's Python scripting API , from function iteration to headless analysis and crypto fingerprinting.

Overview

Manual triage does not scale: a binary with hundreds of functions takes hours to review by hand, while a script examines all of them in milliseconds. This article covers the Ghidra scripting API , the difference between Java and Jython, function and instruction iteration, cross-references, comments, string extraction, crypto constant detection, dangerous-call flagging, and headless batch analysis. After reading, you can write a Jython script that finds the functions worth investigating and run it from the command line.

Required Reading

  • Ghidra Fundamentals - Ghidra interface, data types, cross-references, analysis workflow

Why Script Ghidra

Manual analysis does not scale. A binary with 500 functions takes hours to triage by hand. A script can:

  • Iterate all 500 functions in milliseconds, filter by characteristics, and flag the 5 worth investigating
  • Search for byte patterns (crypto constants, known shellcode, exploit payloads) across the entire binary
  • Cross-reference every call to system() , execve() , and dlopen() - produce a report of dangerous call sites
  • Decode XOR-obfuscated strings automatically by recognizing the decode loop pattern
  • Identify standard library functions that were stripped - strlen , memcpy , base64_encode - by their instruction sequence patterns
  • Export structured data ( JSON , CSV) for ingestion into other analysis pipelines

Script Manager

Window -> Script Manager (green play button icon)

The Script Manager lists all available scripts - built-in examples plus user scripts. The directory is ~/ghidra_scripts/ (or <ghidra_install>/Ghidra/Features/Base/ghidra_scripts/ for built-ins).

To create a new script:

Script Manager -> New Script (green plus icon) -> Python -> name it

Press the Run button or F5 to execute. Use the Run Editor (pencil icon) to edit existing scripts.

Java vs Python

Ghidra supports two scripting languages:

Java - Native Ghidra API . Compiled on-the-fly by Ghidra's built-in compiler. Full access to all Ghidra internals. Documentation at ghidra_docs/api/ . Verbose but complete.

Python (Jython) - Jython is a Java implementation of Python 2.7 running in the J VM . It cannot import CPython C extensions (no numpy, no requests, no cryptography). But it can import and call any Java class, including the entire Ghidra API . Syntax is Python; types are Java objects underneath.

For reverse engineering, Python is preferred: faster to write, less boilerplate, and most Ghidra examples are in Python. The cost is Jython's Python 2.7 limitation - no f-strings, no type hints, no asyncio . Use .format() for string interpolation.

Key Ghidra API Concepts

Every script has access to these global variables (set by Ghidra before your script runs):

Variable Type Description

Flag Dangerous Calls

This script finds every call to system() , execve() , execvp() , popen() , and dlopen()

  • functions commonly used by malware for command execution and library loading. It adds EOL

comments and a summary to the console.

#!/usr/bin/env python2
# dangerous_calls.py - Flag calls to system/exec/popen/dlopen
# Run in Ghidra Script Manager

from ghidra.program.model.symbol import SymbolType
from ghidra.program.model.listing import CodeUnit

DANGEROUS_FUNCS = {
    "system":     "DANGEROUS: calls system() - arbitrary command execution",
    "execve":     "DANGEROUS: calls execve() - process replacement",
    "execvp":     "DANGEROUS: calls execvp() - PATH-searched exec",
    "execvpe":    "DANGEROUS: calls execvpe() - PATH-searched exec with env",
    "execl":      "DANGEROUS: calls execl() - process replacement",
    "execlp":     "DANGEROUS: calls execlp() - PATH-searched exec",
    "execle":     "DANGEROUS: calls execle() - exec with environment",
    "popen":      "DANGEROUS: calls popen() - pipe command execution",
    "dlopen":     "DANGEROUS: calls dlopen() - dynamic library load",
    "dlsym":      "DANGEROUS: calls dlsym() - dynamic symbol resolution",
    "ptrace":     "ANTI-DEBUG: calls ptrace() - debugger detection",
    "fork":       "INTERESTING: calls fork() - child process creation",
    "daemon":     "INTERESTING: calls daemon() - daemonizes the process",
    "setuid":     "PRIVILEGE: calls setuid() - privilege manipulation",
    "setgid":     "PRIVILEGE: calls setgid() - group privilege change",
    "seteuid":    "PRIVILEGE: calls seteuid() - effective UID change",
}


def get_function_containing(addr):
    """Return the function containing this address, or None."""
    fm = currentProgram.getFunctionManager()
    return fm.getFunctionContaining(addr)


def main():
    st = currentProgram.getSymbolTable()
    listing = currentProgram.getListing()
    rm = currentProgram.getReferenceManager()

    found = 0

    for func_name, comment_text in DANGEROUS_FUNCS.iteritems():
        syms = st.getSymbols(func_name)
        for sym in syms:
            sym_type = sym.getSymbolType()
            # Only process FUNCTION symbols (not labels or data)
            if sym_type != SymbolType.FUNCTION:
                continue

            addr = sym.getAddress()
            refs = rm.getReferencesTo(addr)

            for ref in refs:
                from_addr = ref.getFromAddress()
                caller = get_function_containing(from_addr)
                caller_name = caller.getName() if caller else "<unknown>"

                # Add EOL comment at the call site
                listing.setComment(from_addr, CodeUnit.EOL_COMMENT, comment_text)

                print("[{}] {} @ 0x{} : {}".format(
                    func_name, caller_name, from_addr, func_name
                ))
                found += 1

    print("\n=== Summary ===")
    print("Flagged {} dangerous call site(s)".format(found))
    print("Check the Listing for EOL comments at each site.")


if __name__ == '__main__':
    main()

Extract Strings

This script finds all defined strings in the binary, maps them to their referencing functions, and prints a summary. Useful for rapid triage: strings with no cross-references are likely dead data or format strings for unreachable code.

#!/usr/bin/env python2
# string_xrefs.py - Extract all strings and their cross-references
# Run in Ghidra Script Manager

from ghidra.program.model.listing import CodeUnit
from ghidra.program.model.symbol import RefType


def get_function_containing(addr):
    fm = currentProgram.getFunctionManager()
    return fm.getFunctionContaining(addr)


def find_strings():
    """Find all defined data that is a string type."""
    listing = currentProgram.getListing()
    dtm = currentProgram.getDataTypeManager()
    string_type = dtm.getDataType("/string")

    strings = []
    memory = currentProgram.getMemory()

    # Iterate all defined data in the program
    data_iter = listing.getDefinedData(True)
    for data in data_iter:
        dtype = data.getDataType()
        # Check if this data is a string (char[], wchar_t[], etc.)
        type_name = dtype.getName().lower() if dtype else ""
        if dtype and dtype.isEquivalent(string_type):
            strings.append(data)
        elif 'string' in type_name or 'char' in type_name:
            # Also match char arrays that haven't been typed as string
            strings.append(data)
    return strings


def main():
    rm = currentProgram.getReferenceManager()
    strings = find_strings()
    print("Found {} string data items\n".format(len(strings)))

    results = []
    for sdata in strings:
        addr = sdata.getAddress()
        value = sdata.getValue()
        if value is None:
            value = "<binary data>"
        else:
            value = unicode(value)
        refs = rm.getReferencesTo(addr)
        referrers = []
        for ref in refs:
            from_addr = ref.getFromAddress()
            func = get_function_containing(from_addr)
            func_name = func.getName() if func else "<no_function>"
            referrers.append("{}@0x{}".format(func_name, from_addr))

        results.append((addr, value, referrers))

    # Sort by number of references (most-referenced first)
    results.sort(key=lambda r: len(r[2]), reverse=True)

    for addr, value, referrers in results:
        ref_count = len(referrers)
        print("0x{} [{} refs] \"{}\"".format(addr, ref_count, value))
        if referrers:
            for r in referrers:
                print("    <- {}".format(r))
        else:
            print("    <- (no cross-references - dead data?)")
        print("")


if __name__ == '__main__':
    main()

    """Convert Python list/tuple of ints to Java byte[]."""

def search_bytes_in_memory(byte_pattern, pattern_name):
    """Search for a byte pattern in the binary's memory.
    Returns list of (address, offset) tuples where found."""
    mem = currentProgram.getMemory()
    results = []
    blocks = mem.getBlocks()
    pattern_len = len(byte_pattern)
    pattern_java = byte_pattern  # Python list, Java can compare element-wise

    for block in blocks:
        if not block.isInitialized():
            continue
        start = block.getStart()
        end = block.getEnd()
        size = end.subtract(start) + 1
        if size < pattern_len:
            continue
        try:
            block_bytes = mem.getBytes(start, size)
        except MemoryAccessException:
            continue

        # Search for the pattern byte by byte
        for i in range(len(block_bytes) - pattern_len + 1):
            match = True
            for j in range(pattern_len):
                if (block_bytes[i + j] & 0xff) != (pattern_java[j] & 0xff):
                    match = False
                    break
            if match:
                results.append(start.add(i))
    return results

    for byte_seq, name, desc in patterns:
        pattern_name = "{}: {}".format(name, desc)
        hits = search_bytes_in_memory(byte_seq, pattern_name)
        for addr in hits:
            func = get_function_containing(addr)
            func_name = func.getName() if func else "<unknown_function>"
            print("[{}] Found at 0x{} in {}".format(name, addr, func_name))
            add_comment(addr, "CRYPTO: {} found here".format(desc))
            if name not in found_constants:
                found_constants[name] = []
            found_constants[name].append((addr, func))
            total_hits += 1

    # Search integer constants (need to handle endianness)
    mem = currentProgram.getMemory()
    blocks = mem.getBlocks()

    for const_list, name, desc in int_patterns:
        for block in blocks:
            if not block.isInitialized():
                continue
            start = block.getStart()
            end = block.getEnd()
            size = end.subtract(start) + 1
            if size < 4:
                continue
            try:
                block_bytes = mem.getBytes(start, size)
            except MemoryAccessException:
                continue

            # Search for each constant as a 32-bit little-endian dword
            for const_val in const_list:
                le_bytes = [
                    (const_val >> 0) & 0xff,
                    (const_val >> 8) & 0xff,
                    (const_val >> 16) & 0xff,
                    (const_val >> 24) & 0xff,
                ]
                for i in range(len(block_bytes) - 3):
                    if ((block_bytes[i + 0] & 0xff) == le_bytes[0] and
                        (block_bytes[i + 1] & 0xff) == le_bytes[1] and
                        (block_bytes[i + 2] & 0xff) == le_bytes[2] and
                        (block_bytes[i + 3] & 0xff) == le_bytes[3]):
                        addr = start.add(i)
                        func = get_function_containing(addr)
                        func_name = func.getName() if func else "<unknown_function>"
                        print("[{}] Constant 0x{:08x} at 0x{} in {}".format(
                            name, const_val, addr, func_name

    print("\n=== Summary ===")
    print("Total crypto pattern hits: {}".format(total_hits))
    for name, locations in found_constants.iteritems():

Decode XOR Strings

Malware commonly obfuscates strings with single-byte XOR. This script scans for XOR-loops - a small function or code block that loads bytes from memory, XORs each with a constant, stores the result, and loops. Once found, it emulates the XOR operation and re-types the data as a string with an EOL comment showing the decoded value.

#!/usr/bin/env python2
# xor_string_decode.py - Find and decode XOR-obfuscated strings
# Run in Ghidra Script Manager

from ghidra.program.model.listing import CodeUnit
from ghidra.program.model.mem import MemoryAccessException
from ghidra.program.model.data import StringDataType
from ghidra.program.model.symbol import SourceType


def find_xor_decode_functions():
    """Heuristically find functions that perform single-byte XOR decoding.
    Pattern: loop loading byte, XOR with constant, store byte, decrement counter."""
    fm = currentProgram.getFunctionManager()
    listing = currentProgram.getListing()
    candidates = []

    for func in fm.getFunctions(True):
        if func.isThunk() or func.isExternal():
            continue
        body = func.getBody()
        insns = list(listing.getInstructions(body, True))
        if len(insns) < 5 or len(insns) > 80:
            continue

        # Check for XOR with an immediate value and a loop structure
        has_xor = False
        has_loop = False
        xor_immediate = None

        for insn in insns:
            mnemonic = insn.getMnemonicString().lower()
            if mnemonic == 'xor':
                for i in range(insn.getNumOperands()):
                    op_str = str(insn.getOpObjects(i))
                    # Look for XOR with a small immediate constant
                    if op_str.startswith("0x"):
                        val = int(op_str, 16)
                        if 0x01 <= val <= 0xff:
                            has_xor = True
                            xor_immediate = val
                            break
            if mnemonic in {'jne', 'je', 'jnz', 'jz', 'jmp', 'jg', 'jl',
                            'jge', 'jle', 'ja', 'jb', 'jae', 'jbe',
                            'jns', 'js', 'jnz', 'loop'}:
                has_loop = True

        if has_xor and has_loop:
            candidates.append((func, xor_immediate))
    return candidates


def decode_xor_buffer(addr, length, key):
    """Read bytes, XOR with key, return decoded string."""
    mem = currentProgram.getMemory()
    try:
        raw = mem.getBytes(addr, length)
    except MemoryAccessException:
        return None

    decoded = [chr((b & 0xff) ^ key) for b in raw]
    return ''.join(decoded)


def main():
    listing = currentProgram.getListing()
    dtm = currentProgram.getDataTypeManager()

    candidates = find_xor_decode_functions()
    print("Found {} potential XOR decode function(s)\n".format(len(candidates)))

    for func, xor_key in candidates:
        entry = func.getEntryPoint()
        body = func.getBody()
        insns = list(listing.getInstructions(body, True))

        print("[Potential XOR decoder] {} (key: 0x{:02x})".format(
            func.getName(), xor_key
        ))

        # Find the encoded data by looking for LEA instructions
        # that load addresses within the binary (not stack/heap)
        mem = currentProgram.getMemory()
        for insn in insns:
            if insn.getMnemonicString().lower() == 'lea':
                # Check if operand references a global address
                refs = insn.getReferencesFrom()
                for ref in refs:
                    to_addr = ref.getToAddress()
                    # Check if this is in a readable memory block
                    block = mem.getBlock(to_addr)
                    if block and block.isInitialized() and block.isRead():
                        print("  Referenced data at 0x{}".format(to_addr))
                        # Try to decode as a null-terminated string
                        # Find null byte
                        max_len = 256
                        try:
                            raw = mem.getBytes(to_addr, max_len)
                        except MemoryAccessException:
                            continue
                        null_pos = max_len
                        for j in range(len(raw)):
                            if (raw[j] & 0xff) == 0:
                                null_pos = j
                                break
                        if null_pos > 0:
                            decoded = decode_xor_buffer(to_addr, null_pos, xor_key)
                            if decoded:
                                printable = all(
                                    0x20 <= ord(c) < 0x7f for c in decoded
                                )
                                if printable and len(decoded) > 1:
                                    print("  DECODED: \"{}\"".format(decoded))
                                    # Add comment at the data address
                                    listing.setComment(to_addr,
                                        CodeUnit.EOL_COMMENT,
                                        'XOR-DECODED (key 0x{:02x}): "{}"'.format(
                                            xor_key, decoded
                                        ))
                            # Also try without null terminator (fixed length)
                            if null_pos == 0:
                                decoded = decode_xor_buffer(to_addr, 16, xor_key)
                                if decoded:
                                    print("  DECODED (16 bytes): \"{}\"".format(
                                        decoded
                                    ))

        print("")


if __name__ == '__main__':
    main()

Ghidra's analyzeHeadless command processes binaries from the command line - essential for batch analysis, CI/CD pipelines, and server environments.

Flags:

Flag Purpose
-import <file> Import binary into project (creates project if needed)
-process <file> Process a binary already in the project
-preScript <path> Run script before auto-analysis
-postScript <path> Run script after auto-analysis
-scriptPath <dir> Additional directory to search for scripts
-deleteProject Delete project after completion (for one-shots)
-noanalysis Skip auto-analysis (faster for simple scripts)
-readOnly Don't save analysis results
-max-cpu <N> Limit CPU usage (default: all cores)
-analysisTimeoutPerFile <sec> Max analysis time per file
-processor <id> Override processor (e.g., x86:LE:64:default)
-loader <name> Override loader (e.g., ElfLoader)

def get_function_containing(addr):
    fm = currentProgram.getFunctionManager()
    return fm.getFunctionContaining(addr)


def search_bytes(mem, pattern, pattern_len):
    """Search all initialized memory blocks for a byte pattern.
    Returns list of addresses where found."""
    results = []
    blocks = mem.getBlocks()
    for block in blocks:
        if not block.isInitialized():
            continue
        start = block.getStart()
        end = block.getEnd()
        size = end.subtract(start) + 1
        if size < pattern_len:
            continue
        try:
            block_bytes = mem.getBytes(start, size)
        except MemoryAccessException:
            continue

        for i in range(len(block_bytes) - pattern_len + 1):
            match = True
            for j in range(pattern_len):
                if (block_bytes[i + j] & 0xff) != (pattern[j] & 0xff):
                    match = False
                    break
            if match:
                results.append(start.add(i))
    return results


def search_dword(mem, value):
    """Search for a 32-bit little-endian dword in memory."""
    le_bytes = [(value >> 0) & 0xff, (value >> 8) & 0xff,
                (value >> 16) & 0xff, (value >> 24) & 0xff]
    return search_bytes(mem, le_bytes, 4)

Challenge

Reimplement the crypto-constant scanner from this article in Go. Read an ELF file with the debug/elf package, scan each allocated section for the MD5, SHA-1, and SHA-256 initialization vectors, the ChaCha20 sigma constant, and the Base64 alphabet, and print every match with its virtual address. Run it on a binary that links Open SSL or a static crypto library and compare the hits with what Script 3 reports in Ghidra.

package main

import (
	"bytes"
	"debug/elf"
	"encoding/binary"
	"fmt"
	"os"
)

func u32le(vals ...uint32) []byte {
	out := make([]byte, 4*len(vals))
	for i, v := range vals {
		binary.LittleEndian.PutUint32(out[i*4:], v)
	}
	return out
}

type pattern struct {
	name string
	data []byte
}

func patterns() []pattern {
	return []pattern{
		{"MD5 IV", u32le(0x67452301, 0xefcdab89, 0x98badcfe, 0x10325476)},
		{"SHA-1 IV", u32le(0x67452301, 0xefcdab89, 0x98badcfe, 0x10325476, 0xc3d2e1f0)},
		{"SHA-256 IV", u32le(0x6a09e667, 0xbb67ae85, 0x3c6ef372, 0xa54ff53a)},
		{"ChaCha20", []byte("expand 32-byte k")},
		{"Base64", []byte("ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/")},
	}
}

func main() {
	if len(os.Args) != 2 {
		fmt.Fprintln(os.Stderr, "usage: cryptoscan <elf-binary>")
		os.Exit(1)
	}

	f, err := elf.Open(os.Args[1])
	if err != nil {
		fmt.Fprintln(os.Stderr, "open:", err)
		os.Exit(1)
	}
	defer f.Close()

	hits := 0
	for _, section := range f.Sections {
		if section.Flags&elf.SHF_ALLOC == 0 {
			continue
		}
		data, err := section.Data()
		if err != nil || len(data) == 0 {
			continue
		}
		for _, p := range patterns() {
			for off := 0; off < len(data); {
				i := bytes.Index(data[off:], p.data)
				if i < 0 {
					break
				}
				addr := section.Addr + uint64(off+i)
				fmt.Printf("%-10s %-16s addr 0x%08x\n", p.name, section.Name, addr)
				hits++
				off += i + 1
			}
		}
	}
	fmt.Printf("\n%d constant match(es)\n", hits)
}

Build it and scan a normal system binary, then a statically linked crypto binary:

go build -o cryptoscan cryptoscan.go
./cryptoscan /bin/ls
